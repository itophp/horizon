# 前端规则

适用 apps/web，继承根规则。编码前使用 baseline-web-development；新增文案使用 baseline-internationalization；有新 API 需求先回 Goa DSL。

- app 管路由、Provider、布局；features/<feature> 管功能；components/shared 只放真实跨功能复用；components/ui 复用 shadcn 原语。API/SQL 生成目录边界不变。
- React Router 管导航与 URL 状态；TanStack Query 管服务端数据/缓存和取消；Orval SDK 是请求/DTO 来源。页面不裸 fetch，不复制 API 类型或把 query 结果再存全局状态。
- **关联对象选择**：凡选择账号、部门、组织、项目或其他可独立管理的业务对象，无论新增、编辑、筛选、批量还是弹窗，必须使用支持远程搜索的关联选择器，由授权范围内的服务端查询提供候选，显示可辨识名称/辅助信息，提交稳定 ID；禁止要求用户手填 ID、用本地静态列表冒充远程对象，或因候选少而省略远程搜索。单选、多选与树形关系按 [组件指南](../../docs/ui-component-guidelines.md#关联对象选择强制规则) 实现。固定枚举、布尔值和不引用业务对象的纯静态选项不属于关联对象。
- **关联数据展示**：列表、详情、卡片、筛选、弹窗、审批和关联数组等所有用户可见位置，显示关联对象经授权的名称、标题及必要的可区分信息，禁止直接以内部 ID 作为显示内容或加载失败时的回退。人员等适合组合展示的对象使用头像 + 名称等语义组合；多值展示每项名称，数量较多时提供可访问的完整列表。无法读取、已删除、停用及加载失败分别使用本地化且不泄露信息的状态，不能把隐藏对象的 ID 或未经授权名称显示出来。按 [关联数据展示规则](../../docs/ui-component-guidelines.md#关联数据展示规则) 执行。
- 编辑须授权回显历史选中项；无结果、加载、错误、失效和无权限分别处理；上游条件改变取消旧请求并清除或重新验证下游值。候选查询与提交均由服务端执行租户、数据范围和关联有效性校验，前端控件不能代替授权。缺少远程搜索能力时复用或新增受授权的查询能力并经生成 SDK 接入，不退化为手填 ID 或全量拉取。
- 表单使用 React Hook Form + Zod，字段错误存稳定翻译 key，动态语言切换时重新本地化；前端校验不代替后端校验。mutation 不默认重试，设计重复提交与 query invalidation。
- 常规数据表使用 TanStack Table 9 的 features API，数据与列定义保持稳定引用。复杂表格才按需求评估其他工具，不叠加同职能库。
- 新全局客户端状态需有跨页面需要，不能只为服务器数据引入 Zustand；格式化先用 Intl，不无故引入日期库。
- 复用样式 tokens，保留可访问 label/role、键盘和焦点；不自建每页视觉体系。修改公共组件需读取其局部规则并检查调用方。
- 文本、占位、空/错/载入状态、通知、表头及辅助名称全部走资源。i18n:check + lint 自动检查只是部分保障，仍需评估动态文案与 API 错误映射。
- 认证状态/按钮显示只改善体验；真正授权在服务端。不要持久化演示 token，切租户/用户时隔离或清理 query 缓存。
- pnpm 在仓库根可执行 lint/typecheck/test/build/i18n:check；单模块 Vitest 使用 pnpm --filter @baseline/web exec vitest run <路径>。交互覆盖 RTL + user-event；真实流程按 E2E 暂停规则执行（见根 AGENTS.md，只跑映射命中的单个 spec，全量需授权）。

## 页面结构与交互密度

模板只提供 [代码参考](../../docs/code-reference/README.md)，不为规范演示创建产品页面或菜单。AI 工作台、对话、工具步骤与节点 UI 先读 [AI 界面参考](../../docs/ui-ai-patterns.md)，优先核对 shadcn AI Elements 的 Base UI 组合；流程节点复用现有 X6 与 shadcn 内容组件，不为组件示例另起图引擎。

组合与交互开发同时读取 [交互模式](../../docs/ui-interaction-patterns.md)：导航、选择、命令、预览与聚焦任务分别选型，优先复用官方已有交互能力。分页必须接 URL/Query，浮层保留焦点和关闭策略，数据加载/空态/错误分开处理；不能只使用组件外观或用组件数量代替合理性。

实现前必须读取 [页面模板与布局](../../docs/page-templates.md) 和 [组件使用指南](../../docs/ui-component-guidelines.md)，声明模板/布局、主操作、密度、URL 状态与组件复用清单；按需从 [shadcn 官方索引](https://ui.shadcn.com/llms.txt) 查找组件及官方组合方案。实际使用 shadcn/ui 组件源码和交互能力，禁止只抄样式、用原生控件或 div 点击区域替代已有 Button/Input/Select/Dialog 等组件。必要的语义 HTML、Router Link、底层文件输入允许使用。

下列列表/详情约定适用于普通 CRUD；复杂录入采用独立编辑页或分步向导，连续处理采用列表预览，专业任务采用时间调度或画布工作区，选择条件以页面模板为准。短表单优先 EditorDialog，不强制所有编辑操作塞进弹窗。组件指南中的库存与待引入组件必须区分；不存在的组件不得直接导入或声称已实现。

一个页面只承担一个对象的一个视图。列表与详情分路由，多个业务对象用页内标签或独立页面承载；不得把列表、详情、成员、计划、任务及其表单纵向堆在同一屏。功能多不等于要挤进一个页面。

- 列表页 = `PageHeading` + 工具栏（`standalone-toolbar` / `table-toolbar`）+ `DataTable`。行命令走 `RowActions` 溢出菜单，筛选与搜索写进 URL 查询参数。卡片视图复用 `role-card` 的结构，与列表视图共享同一套命令函数。参考 `features/administration` 的账号、组织、角色页面。
- 详情页 = `PageHeading`（含返回与主操作）+ 概览 `admin-panel` + 子对象标签（`Tabs`）。子对象的增删改通过 `EditorDialog`，页面上不出现常驻表单。
- 简单对象的新增、编辑、只读查看优先复用 `EditorDialog`；复杂对象详情分路由，复杂编辑使用独立页或向导。按来源切换标题，表单拆到 `forms.tsx`，列表与面板各占独立文件。单个组件文件接近 300 行、或同时处理两个以上业务对象时必须拆分。
- 常驻表单只允许出现在「表单即页面主体」的场景（独立创建/编辑页、分步向导、系统设置、发送通知、登录），按模板条件在实现说明里记录选择理由。设置页不能当作业务列表页的参照。
- 禁止：一个 section 内「表格 + 常驻表单 + 多个子对象面板」纵向排列；为省事复制 `DataTable`、筛选或行操作逻辑；另写一套与工具栏不一致的下拉控件。
- 提交前自问两点：第一屏能否看清「当前对象」和「可执行动作」；新增/编辑是否以弹窗或独立页打断，而不是把页面越撑越长。

## 界面风格一致性

新建页面、扩展功能和局部改版必须与当前已确认的同类界面保持一致。实现前先查看现有参考页面及源码，读取 [设计系统](../../docs/design-system.md)，确定可复用的布局、组件和 tokens；不能仅凭通用模板或个人审美另起一套视觉体系。

- 后台以现有账号、组织、部门、角色和权限页面为基准，优先复用 features/administration 的公共布局、PageHeading、DataTable、EditorDialog 与状态组件。登录页延续现有登录页风格；/foundation 技术示例不作为后台的视觉基准。
- 保持页面框架、背景层级、字体与字号、间距和信息密度、圆角、边框、阴影、按钮/表单/表格、图标及交互状态一致；浅色和暗色沿用同一套语义 tokens。不得为单个页面新增独立配色、布局体系或同职能 UI 库。
- 后台沿用侧栏底色包裹独立内容面板的结构：边框和圆角属于内容面板，正文内部滚动，顶栏/页脚与圆角保持固定；不恢复外围留白、侧栏分隔边框或整页滚动。具体数值以现行设计系统和公共样式为准。
- 缺少现成组件时，按现有视觉语言补充可复用组件；调整公共样式需核对所有调用页面。验收在相同视口下对照同类页面，检查浅/暗主题、交互状态及滚动后的整体一致性。
- 用户明确要求改变视觉方向时按最新要求执行，并同步设计系统及受影响的公共页面；一致性规则不能覆盖用户最新指示。

## 信息架构与菜单

侧栏只保留一级入口：AI 工作台、数据统计、业务能力、流程编排、账号管理、组织管理、权限管理、Agent 协作、系统设置（知识库入口暂时隐藏，`/knowledge` 路由保留）；个人偏好与通知中心从顶栏进入。部门、角色、字段（字典）不再是独立菜单项，分别并入组织管理、权限管理、系统设置的标签内；附件管理只保留路由，不占菜单位置。

- `/` 是默认入口，解析到 AI 工作台（`/ai`）；没有 `assistant:use` 的账号落到数据统计（`/analytics`），不进入无权访问的页面。数据统计沿用原工作台看板，路由固定为 `/analytics`。

- 合并页面用页内标签承载各自职责：组织管理 = 组织架构 / 部门，权限管理 = 角色授权 / 账号独立授权 / 角色管理，系统设置 = 系统配置 / 字段管理，Agent 协作 = MCP Server / WebMCP / WebSkills 三个标签。新增能力按归属追加标签，不要再起平行菜单项。
- 标签可见性与默认标签由正式读取权限决定（organizations:read 或 departments:read、access:manage 或 roles:read、settings:read 或 dictionaries:read），前端隐藏只是体验，服务端授权不变。搜索等页内状态更新保留 URL 其他参数，避免切换标签丢失。
- 旧路由 `/departments`、`/roles`、`/dictionaries`、`/webmcp`、`/mcp-settings` 只做重定向，不恢复页面组件；新增或调整入口时同步 WebMCP 路由清单与对应 E2E spec（只在授权范围内执行）。
- 业务能力页 `/capabilities` 及方案详情遵循 docs/security.md：按钮通过 `@/lib/capabilities` 调用 Gateway，必须带稳定的 `idempotencyKey`；页面不得直接调用业务接口或自行判断审批。列表、事件与调用轨迹读服务端返回值，事件上的 AI 状态只展示不猜测。
- 流程编排页 `/orchestration` 的运行目录与编译图只读：目录与编译图来自 `orchestration.workflow.list` / `orchestration.workflow.diagram`，运行、取消与审批复用既有能力与审批队列；前端可在当前视图建立本地草稿：控制／分支线插入节点、节点两侧新增带 when 的同级分支，支持节点移除、自动重连及撤销和重置；移除不能猜测替代条件或字段输出，仍有引用时明确拒绝。必须明确尚未保存／发布，原字段映射不得丢失，运行操作仍只执行已注册版本，不得把投影当完整 DSL 上传。X6 支持平移、缩放及节点选择，节点属性与连线类型来自服务端投影，输入 Schema 单独查看。不推断节点业务语义，未编译节点必须显式标注；不得按同名能力的调用记录推断具体步骤已完成。
- 业务模块（设置、字典、文件、通知、MCP、账号）的按钮只调用 `apps/web/src/lib/capabilities.ts`；禁止直接 `fetch` 旧 REST 路径，也禁止按模块另写调用层。业务类型在 `apps/web/src/api/types.ts`，会话/能力类型仍在生成的 models 中。
- AI 工作台是单一页面 `/ai`，用 `?tab=chat|runs` 承载对话与执行记录；入口按 `assistant:use` 显示。审批队列属于 capability 服务，AI 页只展示与决策，不复制审批逻辑。风险等级、审批状态、执行轨迹必须读服务端返回值；审批卡片只展示服务端投影的参数，不得回传或渲染审批载荷正文。详见 [ADR 015](../../docs/decisions/015-capability-centric-platform.md)。
- 顶栏「申请临时访问」为纯图标按钮，必须保留 aria-label/title；顶栏不再显示“系统管理中心”之类的装饰文字。

权限界面使用后端 PermissionDefinition 目录的一/二级层次，一级模块用真实 rowSpan 合并；不得硬编码另一套权限代码。临时申请入口对已认证账号可见，审批入口按服务端 canReview 显示。申请与最终批准分别展示，支持审批修订权限、时效和范围；前端计时/隐藏按钮不能代替服务端授权、审批上限和到期判断，语义见 [ADR 003](../../docs/decisions/003-temporary-access.md)。

账号多部门配置和上下文切换遵循 [ADR 004](../../docs/decisions/004-department-memberships.md)。每个部门独立编辑角色与权限覆盖；切换仅调用生成 SDK，取消旧请求、清除私有 Query 缓存并重建页面。不能在浏览器合并各部门授权；申请/审批显示绑定部门。权限行为改变须同步 baseline-security 及相关规则。

内置管理员账号仍禁止停用、删除及移动受保护主部门；界面中主部门策略的锁定不能连带隐藏本人添加附加部门的入口。附加部门仍独立配置角色/覆盖，遵守既有正式权限与范围校验。其他账号不能编辑内置管理员，详情模式及无部门授权管理权限时，部门策略控件保持只读。 账号编辑的入口明确标为“部门与权限”，不要用主部门策略保护开关同时关闭部门归属管理。

系统治理页面复用 features/governance 的 ChangeHistory、运行时配置和生成 SDK；系统设置与字典不再关联配置范围；发布/回退/重新认证在服务端完成，浏览器不保存证明或 SMTP 密码。Query 键包括租户、账号、当前部门、语言与目标范围/版本，切换仍清私有缓存。个人偏好以服务端值优先，原浏览器值仅首次迁移；运行时字典和 Logo 使用明确消费入口。权限目录的扩展操作不能因旧四列矩阵而丢失，仍保持一级真实合并单元格。详见 [ADR 005](../../docs/decisions/005-system-governance.md)。

业务需要设置项、选项、上传/读取/下载或通知时先使用 [baseline-shared-capabilities](../../.agents/skills/baseline-shared-capabilities/SKILL.md)，不要只在管理页面开发时才读取公共能力约定。

通知中心见 [ADR 008](../../docs/decisions/008-notification-center.md)：侧栏不放菜单，入口是顶栏右上角铃铛；投递记录不嵌入设置。人工消息复用 NotificationComposer/NotificationMarkdown、受控组织选择与生成 SDK；禁止 raw HTML/MDX 和任意文件 URL，通知附件使用绑定鉴权入口。收件人预览后发送时仍以后端重新解析为准。发起通知是通知中心的按钮入口，跳转独立页面 `/notifications/compose`，正文使用 features/governance 封装的 MDXEditor 所见即所得编辑器；工具栏不提供上传插入文件、源码/差异/预览浏览，新增编辑器文案走 i18next 且浅暗主题沿用后台 tokens。新增路由同步 WebMCP 路由清单。

WebMCP 接入遵循 [ADR 009](../../docs/decisions/009-webmcp.md)。页面工具通过 features/webmcp 与 lib/webmcp 注册白名单，随路由卸载；不能直接暴露任意 JS、Query 缓存或凭证。账号工具只操作已有授权数据的只读详情/筛选，业务写入未开放。连接显式开启，身份/部门变化和退出/401 必须撤销；新增工具补输入、权限拒绝、范围外 ID 和生命周期测试。开发服务器 `/__webmcp/connection` 只用于把本机服务的端口与配对密钥预填进表单：仅 serve 生效、Host 必须回环、Origin 必须同源、`no-store`、无 CORS 头、失败返回 404；不得扩展为任意文件或配置读取，构建产物中不得出现该端点。未来助手复用同一工具定义，不绕过生成 SDK 或后端范围。远程 MCP、WebMCP 与 WebSkills 合并在 `/mcp` 单页，按标签切换（`?tab=remote|page|skills` 只是入口提示）；新增 Agent 接入内容按标签拆成可复用区域，不再另起独立页面，旧 `/mcp-settings`、`/webmcp` 只保留重定向。

新增路由同步 WebMCP 路由清单并声明是否允许连接；新增工具声明 global/module/page 层级、权限及操作类型，测试应验证其可用范围和撤销。模块/页面上下文是基础适配，不代表业务流程已适配；业务操作应复用页面真实动作和现有服务端授权，并通过真实 MCP 链路及必要的用户交互测试验证。

组织、部门及角色的搜索工具复用现有列表搜索状态，只返回请求确认；必须验证对应 read 权限、加载状态以及真实显示结果。

系统设置定时发布见 [ADR 010](../../docs/decisions/010-settings-schedules.md)：保存草稿后调用生成的排期接口；datetime-local 明示设备时区并转 UTC，不能靠浏览器定时器执行。pending 草稿不再直接发布，支持取消及状态/错误展示；敏感排期走单次重新认证，状态变化刷新已发布配置与历史缓存。

账号远程 MCP 按 [ADR 011](../../docs/decisions/011-remote-mcp.md)：工具复用原授权用例，凭证绑定本人/部门和固化集合；敏感管理操作重新认证，身份变更撤销与延迟归属检查、客户端配对/备份及协议专项测试同步维护。禁止将安装状态当连接成功。

浮动工作区智能体只有一个入口：业务能力与 WebMCP 页面工具由同一服务端 Eino Agent 选择；页面只执行服务端返回的待处理调用，并在执行前核对当前注册表、名称及 Schema。切换租户、账号、部门时重新挂载对话状态并取消旧请求。不得恢复页面／Agent 两套模式，也不得在浏览器内复制业务工具执行逻辑。详见 [ADR 012](../../docs/decisions/012-embedded-assistant.md)。

会话的 authorizationVersion 是非敏感授权版本，只用于缓存隔离与失效，不能替代服务端权限。授权版本变化时先取消并移除私有缓存，再发布新 profile；不因普通 Me 刷新或令牌刷新丢弃未修改权限下的草稿。Runtime 查询身份必须包含该版本。

## 远程 MCP 动态能力目录（现行）

远程 MCP 与 AI 助手共享自动化能力发现；Token 绑定账号和部门，每次请求按当前正式权限重建目录，历史固化工具集合不再限制能力。业务调用必须经 Gateway，并保持来源、数据范围、审批和幂等检查；手动和内部专用能力不进入自动化目录。权限变更须覆盖发现、猜测调用和撤权后的拒绝。详见 docs/security.md 和 docs/decisions/011-remote-mcp.md（从仓库根解析）。
