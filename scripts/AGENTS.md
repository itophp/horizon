# 工程脚本与门禁

继承根规则；修改门禁使用 baseline-quality-gates。

脚本默认从自身位置解析仓库根，不依赖用户终端 cwd。成功/失败用正确退出码，保留子进程退出码和可读诊断；禁止吞异常、静默跳过工具/数据库/浏览器缺失。

规则清单在 docs/agent-policy.json；新增/移动 Skill、子目录规则或检查命令时同步清单和任务矩阵。check-rules 验证结构、元数据与本地链接，不能声称它证明自然语言合规或业务安全。

生成只写约定目录；源 DSL/SQL 不被生成脚本覆盖。生成一致性检查与 E2E 串行。安全检查不能用容易绕过的 grep 扫描冒充完整安全审计；优先复用真实静态规则和负向行为测试。

新/改脚本先运行自身及有意义的失败路径；不要添加只比对说明文字的测试。脚本/Skill 的语义仍需按具体开发任务审核。

WebMCP 本机服务与安装器按 [ADR 009](../docs/decisions/009-webmcp.md) 运行：默认 18793 loopback，配对密钥只在受限文件与 Authorization，Host/Origin 精确校验。setup 仅 allowlist 客户端与有效已连页面，不能接收任意命令/路径。全局配置只在显式安装时备份并合并；坏配置拒绝覆盖，失败正确报告，不能将部分写入宣称安装成功。新传输/安装入口须补真实成功和拒绝测试。
