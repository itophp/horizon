# Application Runtime 数据库定义实施记录

## 架构与边界

部署交付可信代码和声明基线；数据库保存租户不可变应用版本，当前发布指针决定生效内容。Runtime 文档格式为 2.2，兼容旧格式的内存转换。Entity、Capability、SQL、组件实现和 Workflow 代码仍由正常部署交付，数据库只保存声明及固定代码引用，不执行脚本或远程代码。

本轮使用现有 Capability Gateway、IAM/Policy、Plugin Manager、Eino ADK/Workflow、检查点、Outbox、TanStack Query、React Hook Form/Zod 和生成 SDK。没有新增依赖。Memory Center 继续沿用现有权限与渠道规则，不是定义或发布状态的事实源，其人工专用能力未加入设计 Agent。

## 存储和版本

迁移 `00028_runtime_definitions.sql` 新增部署快照、租户版本、当前指针和变更历史。快照与版本由数据库触发器禁止更新和删除；发布/候选指针在事务提交时检查同租户、同应用的版本引用。安装和应用启停继续使用已有表。

- 应用配置版本采用四级数值解析，例如 `1.2.3.4`。前三位来自部署基线，第四位在事务锁内分配；调用方不能指定。
- 提案需要当前父版本和头修订。结构、引用、权限或资源校验失败时不分配版本；幂等重试返回原调用。
- 发布固定绑定候选版本、摘要及头修订，仅切换指针；回退复制旧内容生成新版本，修订不倒退。
- 安装、应用运行修订及配置内容版本相互独立。有效租户目录修订由保留墓碑的安装修订和应用运行修订之和计算，发布/生命周期变化单调递增；草稿修改不改变有效目录。
- 文档上限 1 MiB，提案最多 100 项稳定 ID 变更；表达式、查询、关系和子表仍受已有预算限制。

## 解析、启动和生命周期

应用/页面解析、Provider、Action、语义上下文、AgentProfile、工具发现及调用新鲜度检查读取数据库已发布快照。内存目录仅用于可信代码可用性、部署基线和离线校验；数据库缺失时不回退为默认启用。

启动在就绪前通过固定 `application.runtime.catalog.reconcile` 能力登记部署快照。Gateway 和执行端同时限制系统账号及事件来源，自动化发现排除此能力。租户事务锁、唯一键与 Gateway 幂等避免重复登记；同部署重启不生成版本，也不覆盖定制。新租户通过显式初始化模板在事务内建立基线与发布指针。

安装、启停、卸载、重装、升级与回退在现有基础设施事务中维护状态、定义指针、历史及 Outbox。卸载保留版本、业务记录和审计；重装保持包停用，并保留应用单独启停配置。Runtime Host 不能通过普通插件操作停用或卸载，动态应用仍可单独管理。

包升级采用旧基线/当前定制/新基线三方合并，按稳定声明 ID 识别修改和顺序；重叠修改返回冲突路径。带定制或待处理候选的升级须绑定人工审查过的候选版本、摘要及修订，包版本和定义指针原子切换。普通发布不能绕过生命周期切换至另一包版本。原有活动任务、审批及依赖限制继续适用。

发布与生命周期事件只携带 ID、版本、修订和动作摘要，不包含定义正文。前端目录轮询和授权范围指纹负责失效；服务端逐次验证版本、摘要、目录和安装修订，事件延迟不能使旧提交继续生效。

## 定义能力与设计入口

固定能力包括 definition 的 list/get/history/inspect/contracts/validate/diff/preview/create/propose/publish/discard/rollback/rebase，以及 baselines/rebase.check。定义仍只由模块 Entries 注册一次。

- `applications:read` 读取授权定义；`applications:design` 为正式设计权限；`applications:manage` 管理发布、回退及生命周期。新权限不能临时申请，不自动授予普通角色。
- 发布/回退为 high、manual-only、HumanUI-only。设计 Agent 固定工具集不含发布、回退、安装和权限管理。
- 设计者与发布者都按当前正式权限重新验证引用。内层 Gateway 仍强制字段、范围、风险与来源；声明不能移除可信扩展的权限/依赖或覆盖能力政策。
- 新应用由服务器生成稳定 ID，路由限定 `/apps/<slug>`；创建和首次发布保持停用，须显式启用。
- 应用自有文本通过 `$app:key` 绑定到独立本地命名空间，要求双语完整；其他翻译只引用可信部署已有键。主题仅允许本应用前缀及受限 CSS 值。资源按不可变版本加载和释放。

`/applications/design` 提供需求输入、固定 Workflow、真实任务状态、候选版本、声明影响清单、完整差异、校验结果、隔离预览、发布、回退、弃稿、基线合并及启停。发布确认固定用户实际审查的快照，后台刷新不会替换确认对象。

预览重新授权读取 Provider；写动作和自定义业务视图不执行。候选导航不进入普通工作区。新定义发布无需重启；已有脏表单保留本地内容并拒绝旧版本提交。

设计 Workflow 复用 Eino ADK 和持久检查点；原生写工具先保存检查点再执行。contracts 工具分页发现当前正式权限可用的固定能力、实体字段和可信组件，不返回业务记录；设计 Agent 根据真实工具结果返回版本。版本中的 Agent runId 来自可信任务上下文，浏览器不能伪造。

## 安全回归处理

七处旧用例的正式授权夹具已写入数据库真实身份。伪造账号/租户 Principal 在 Gateway 拒绝；撤权后不能继续用禁用账号查询任务。未缩小 Gateway 的实时身份重建范围。

另修复有效会话的临时授权恢复：人类会话从数据库验证会话并重建正式权限与仍有效的临时权限，二者保持分离。后台、Agent、Workflow 和审批恢复继续只使用正式任务身份。
