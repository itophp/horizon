# ADR 007：公共设置和字典统一管理

状态：按用户 2026-10-29 最新要求执行；本决策替代 ADR 005 中企业/公司/部门配置范围、继承及字典覆盖的设计，其余发布、版本、安全、存储和通知约束继续适用。

系统设置与字典属于当前工作空间的公共能力。页面不再选择/关联企业、公司或部门，不维护部门覆盖或字典本级扩展。运行时设置只解析公共设置和允许的本人偏好，恢复默认值区别于显式空/false/0。个人偏好仍使用本人入口，不扩大到安全或存储参数。

公共不等于公开或跨租户。管理操作需要正式权限以及工作空间完整授权，旧的部门范围授权不会自动扩大。权限目录将设置及字典管理标为不配置数据范围，新配置由 UI 使用 ALL；历史受限授权仍受服务端范围检查。字典消费仍独立检查 dictionaries:use，动态组织/部门/角色/账号来源继续复用原资源权限与当前部门数据范围。文件和消息继续按原有账号/部门/租户隔离。

接口保留 workspace:0 等内部兼容元数据，不把这些字段作为用户配置项；列表/详情查询仅接受默认工作空间，组织目标和旧字典覆盖写入被拒绝。历史组织设置和覆盖记录保留用于审计/恢复，但不再参与有效配置，也不能通过旧草稿/版本接口重新发布。

追加迁移将已有字典及字典项统一到工作空间，保留代码、ID 和引用；来源不同的默认项冲突时优先保留原定义层默认项，再按排序/ID 确定一个。旧字典版本文档在读取、发布及回退时投影为公共目标，既有版本正文不重写。组织级设置不能自动合并，尤其不能移动绑定旧范围 AAD 的密文；公共设置值保持不变，原组织值仅保留历史。数据归并不会在迁移 Down 时重新拆分或删除稳定引用。

业务接入使用 [公共能力 Skill](../../.agents/skills/baseline-shared-capabilities/SKILL.md) 和 [接入约定](../shared-capabilities.md)。新增业务参数、选项和文件能力优先复用已有模块；扩展消费者、契约或权限时同步这些入口与真实回归。
