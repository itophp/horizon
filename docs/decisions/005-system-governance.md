# ADR 005：系统设置、字典、通知与附件

状态：正式实施决策；配置范围已由 [ADR 007](007-global-governance.md) 调整，通知菜单/人工消息以 [ADR 008](008-notification-center.md) 为准；实际验收记录见 ../verification.md。

设置、字典、附件和通知独立服务，共享已验证的 identity Principal、Casbin 与永久授权/Scope 接口。所有管理写使用正式权限；配置/字典拥有范围不能套用账号任意归属匹配。现有角色不因新增目录自动扩权。

设置由注册表定义类型/默认值/适用范围/敏感性与消费者。覆盖值区分重置和显式空/false/0；继承链仅来自当前可信部门。草稿、版本、发布与脱敏审计在事务提交，基准版本防止丢失更新。敏感发布/回退使用绑定会话、部门、动作、资源和版本的五分钟单次重新认证凭据；不增加审批工作流。SMTP 密码以环境根密钥加密，所有 DTO/导出/历史均脱敏。

字典静态项使用稳定代码及数据库 ID，发布后不删除/改码；停用仍支持历史解析。树与范围覆盖不改变稳定身份，动态提供器复用原资源授权，只输出选项投影。发布/回退须再次验证默认项、树结构、引用和当前范围。

本地存储位于部署允许根目录内，业务文件名不作为物理路径。驱动注册接口覆盖校验、读写、删除、探测；仅注册 local。文件记录绑定不可变存储配置版本，修改位置/访问地址只影响新文件；旧配置被引用时不能删除。受控公开品牌 Logo 与私有文件下载分开，不暴露整个存储目录。

临时权限状态变化与通知事件同一数据库事务提交，持久化队列做幂等分发及有界重试。站内消息绑定接收账号和部门上下文；SMTP 发送前复验账号/归属/权限，属于至少一次投递，不承诺外部服务 exactly-once。本人撤销不再通知自己。

沿用原有技术栈，不引入 Redis/MQ 或第三方存储 SDK。上传独立体积及超时限制，其他 JSON 入口仍保持小体积边界。数据库迁移只追加、旧数据默认行为不变；部署、密钥、存储备份与真实 SMTP 凭证在环境配置中明确，不在仓库提交。

会话时长收紧必须在发布事务内永久缩短既有 expires_at，并清理已经超过新空闲时限的会话；认证发现过期时撤销该会话。以后放宽策略不能复活已经终止的会话，也不能延长已签发到期时间。

账号删除级联清理本人的偏好、会话、消息及个人配置历史；不能因改过主题而阻止既有账号删除。共享发布/审计中的 actor_id 和附件 owner_id 通过 gov_identity_refs 保留不可复用的历史身份 ID，复合外键继续禁止跨租户引用；映射由账号插入触发器维护，其来源仍为可信 Principal，不能由请求指定；删除账号不删除共享发布或附件。组织/部门配置和品牌历史绑定仍保持引用保护。迁移回退若无法重建旧的活跃账号外键，应明确失败，不能删除历史审计/附件来强行回退。
