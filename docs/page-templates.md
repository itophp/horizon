# 页面模板与布局选择

状态：本文定义页面规格与验收标准，不表示所有模板都已有可运行组件。现有基础为 administration/shared.tsx 的 PageHeading、DataTable、RowActions、EditorDialog。提供不挂载的代码参考，见下节；模板按业务需要提取使用。组件选型见 [组件使用指南](ui-component-guidelines.md)，主题与外壳见 [设计系统](design-system.md)。

## 代码参考

模板以文档与不挂载的源码提供，应用不注册示例页面、路由或菜单。参见 [UI 代码参考](code-reference/README.md)：布局、短表单和流程节点内容可以按业务任务提取；回调、翻译、数据、权限与状态由实际 feature 接入。AI 工作台及执行轨迹选型见 [AI 界面参考](ui-ai-patterns.md)。参考代码不是已接入的业务功能。

## 实现前的页面声明

每个新页面在实现说明中列出：主要用户任务、页面模板编号、布局编号、主操作、信息密度、URL 状态、组件复用清单、缺失组件和全部数据状态。参考页面只作辅助，不能代替这些决策。

涉及关联业务对象的表单、筛选、批量操作与弹窗，必须使用授权范围内的远程搜索选择，显示名称并提交稳定 ID；禁止让用户填写内部 ID。按 [关联对象选择强制规则](ui-component-guidelines.md#关联对象选择强制规则) 处理回显、失效、级联与服务端授权；缺少查询能力时先补能力，不用静态选项绕过。

所有页面展示关联对象时按 [关联数据展示规则](ui-component-guidelines.md#关联数据展示规则) 显示授权的标题或名称；人员可组合头像与名称，多值展示可访问的名称集合。内部 ID 不直接展示，缺少名称或无权查看时使用安全的本地化状态。

统一视觉语言；根据任务改变信息结构。不得为增加变化添加无业务意义的统计卡、图表、Tabs 或装饰面板。一个页面服务一个主要任务；关联对象可通过 Tabs 或子路由展开。

## 七种布局骨架

以下数值是新模板建议起点，现有 shell 与公共 tokens 优先；落地到公共布局时集中管理，不在每页硬编码。已有页面不因本文自动改版。

| 编号 | 骨架 | 桌面结构 | 窄屏策略 |
| --- | --- | --- | --- |
| L1 | 单主区 | 标题 → 工具栏 → 主内容 → 分页，表格使用可用宽度 | 工具栏换行；保留核心列，其余进入详情；必要横向滚动限于表格容器 |
| L2 | 主次双栏 | 主区 minmax(0, 1fr)，辅助区约 280–360px；间距 24px | 辅助信息移到主区之后；核心状态与操作保持靠前 |
| L3 | 导航与内容 | 左侧分类/树约 220–280px，右侧内容 | 分类入口收为 Sheet 或 Select；保留当前路径 |
| L4 | 列表与预览 | 列表约 320–400px，预览占余宽；可用 Resizable | 单栏列表，选择后进入详情；返回恢复列表位置 |
| L5 | 分区仪表盘 | 摘要 → 主要分析 → 辅助明细；主次图表可用 2:1 比例 | 单列，按业务重要程度排序；图表保留可读高度 |
| L6 | 聚焦流程 | 表单主体约 640–800px；复杂双列表单可至 960px；步骤在顶或侧 | 字段单列，步骤压缩为当前步骤与总进度 |
| L7 | 工作区 | 顶部工具栏，左工具/对象树，中间画布，右属性；可调面板 | 工具与属性用 Sheet 按需打开；核心任务不依赖悬停 |

外壳继续使用 console-main / console-content；顶栏与页脚固定，正文独立滚动。多面板工作区可以有清楚归属的独立滚动区，禁止叠加无意义的多层滚动。

## 六种基础模板

### B1 标准业务列表（L1）

- 适用：账号、客户、合同等需要比较、排序、筛选和批量处理的记录。
- 结构：PageHeading（标题/说明/主操作）→ 搜索筛选工具栏 → 已用筛选与结果数量 → DataTable → Pagination。
- 组件：Input/InputGroup、Select/Combobox、Button、Table + TanStack Table、Checkbox、Badge、DropdownMenu、Pagination；行命令复用 RowActions。
- 默认只突出一个页面级主操作；选中记录后显示批量操作与选中数，说明跨页选择范围。行点击不取代可访问的详情链接。
- 搜索、筛选、排序、页码写 URL；改变筛选回到第一页；客户端不能将一页数据排序伪装成全量排序。
- 禁止：列表下面常驻编辑表单、每行一串高强调按钮、无实际数据的统计卡。

### B2 对象详情（L2，必要时 L1）

- 适用：围绕一个对象查看状态、关系、活动与业务操作。
- 结构：返回/路径 → 对象名称、状态、主操作 → 关键摘要 → 业务 Tabs/子路由；辅助栏展示归属、日期和活动摘要。
- 组件：Breadcrumb、Badge、Tabs、Card/Separator、Avatar、Table、DropdownMenu；时间线由语义列表组合，不伪称 shadcn 内置 Timeline。
- 首屏回答“是什么、当前状态、接下来能做什么”；子对象单独列表，增改走 Dialog 或独立编辑页。
- URL 保留选中标签；直接访问、无权限、对象不存在分别处理；活动不能泄露不可见字段。

### B3 分类与树管理（L3）

- 适用：组织、分类、目录、资源分组。左侧定位，右侧查看或管理选中节点。
- 组件：Input、Collapsible、ScrollArea（确需时）、DropdownMenu、Breadcrumb、DataTable、Dialog。
- shadcn 未覆盖的完整树交互需按其原语组合为共享组件，补充展开、选择、键盘与层级语义；不能把 Collapsible 自动等同完整 Tree。
- 选中和展开是两种操作；删除说明子节点影响；无节点与无搜索结果分开；窄屏切换分类后关闭导航面板。

### B4 创建与编辑（L6 或 EditorDialog）

- 适用：集中录入、校验、提交一项业务数据。
- 短表单、单一分组、少量字段优先 EditorDialog；约 8 个以上字段、多个分组/子表、附件预览、需持续参考资料或长时间编辑时，评估独立页。数量是判断起点，以实际复杂度为准。
- 结构：标题/说明 → FieldGroup 分组 → 校验与提交错误 → 取消/保存；独立页可用固定操作区，但不得遮住字段。
- 组件：Field、Input、Textarea、Select/Combobox、RadioGroup、Checkbox/Switch、Calendar、Alert、Button；RHF + Zod 管状态。
- 短表单单列，相关且短的字段才双列；说明紧随字段；必填有统一标记与文字说明。失败保留输入，定位首个错误；离开有未保存草稿时给出明确选择。
- 查看模式默认使用可读文本而非满屏 disabled 控件；仅简单对象可复用同一 Dialog 的只读模式。

### B5 设置与配置（L3 或 L6）

- 适用：系统配置、个人偏好、集成设置；表单为主体。
- 结构：分类导航 → 分类标题/影响说明 → 语义分组 → 保存反馈；高风险区独立放在末尾。
- 组件：Tabs 或分类导航、Field、Switch、RadioGroup、Select、Alert、Separator、Button、AlertDialog。
- 每组明确采用即时保存还是统一提交；不得让同组控件无说明混用两种语义。密钥不回显原值，敏感更改走现有服务端安全流程。
- 小量设置直接分组，不强制每个字段套 Card；多层 Card 嵌套不能代替信息架构。

### B6 工作台与数据看板（L5，两个变体）

- 工作台：突出待办、近期对象、快捷动作；依行动优先级排序。数据看板：突出指标、趋势、异常及钻取入口。
- 结构：范围/时间选择 → 少量核心摘要 → 一个主要任务区或图表 → 次要分析/明细。
- 组件：Card、Item、Chart、Table、Progress、Badge、Tabs、Date Picker、Skeleton、Empty。
- 指标写清单位、统计范围、更新时间、比较基期；无权限不显示伪造的零值。卡片宽度和图表面积体现主次，避免棋盘式等权排列。
- 图表按问题选型，见组件指南；每张图提供结论或可理解的标题与数据明细入口。

## 六种专业模板

### P1 审批与业务处理（L2）

- 主区：请求摘要 → 业务材料 → 差异/依据 → 历史；辅助区：流程状态、申请人和处理动作。多条连续处理可组合 P2。
- 组件：Badge、Table、Tabs、Textarea、Alert、Button、AlertDialog、ScrollArea；附件调用共享文件能力。
- 同时展示原始申请和最终结果；拒绝原因按业务要求校验；提交期间锁定决定，冲突后刷新，不能重复处理。权限与审批由后端执行。
- 业务人工任务和 Gateway 风险审批明确区分；固定操作区不遮挡材料，敏感信息按授权投影。

### P2 列表与预览（L4）

- 适用：通知、待办、审核队列等需要连续浏览处理的任务。
- 结构：队列工具栏 → 可定位的列表 → 选中项预览与动作；用 URL 记录选中项。
- 组件：Item、Badge、Avatar、Separator、Resizable、Skeleton、Empty；预览里的表单使用 Field。
- 选择变化、加载、记录消失、处理后下一条和滚动恢复有明确行为；键盘可打开记录，窄屏保留返回路径。预览加载失败不清空整个队列。

### P3 时间与计划调度（L1 或 L7）

- 适用：日历、排班、里程碑、任务看板、甘特计划；按任务选择时间或阶段维度。
- 结构：日期范围/视图/负责人筛选 → 主计划区 → 事件详情或编辑。
- 组件：ButtonGroup/ToggleGroup、Popover + Calendar、Badge、Tooltip、Sheet/Dialog。
- Calendar 是日期选择器，不是完整业务日历；shadcn 无完整甘特/拖拽看板，优先组合现有组件，专用引擎确有需要才评估依赖与许可证。
- 拖拽同时提供键盘/菜单替代；显示时区、冲突、跨日和失败回滚；窄屏提供议程/列表视图。

### P4 编辑与可视化编排（L7）

- 适用：流程、文章、报表等需要持续编辑与预览的工作区。
- 结构：名称/保存状态/发布动作 → 对象工具 → 中央编辑区域 → 属性面板；复杂工作区独立布局，沿用主题与权限。
- 组件：Resizable、Tabs、Tooltip、DropdownMenu、ContextMenu、Sheet、Field、AlertDialog；图编辑/富文本引擎按项目实际选型。
- 保存、校验、发布职责分开；显示脏状态、失败和版本冲突；撤销/重做只在真实支持时提供；不能用示意画布冒充可执行流程。

### P5 内容与资源集合（L1）

- 适用：应用、模板、知识、文件与素材，以识别和发现为主。
- 结构：标题/主操作 → 搜索/分类/排序 → 卡片或紧凑列表 → 分页；两种视图共享筛选与命令。
- 组件：Card/Item、AspectRatio、Avatar、Badge、DropdownMenu、ToggleGroup、Pagination、Empty。
- 图片比例统一，有无图回退；标题可访问，操作菜单不嵌套在整卡链接中；不对需要跨列比较的数据强制卡片化。

### P6 分步向导与批量导入（L6）

- 适用：有前后依赖的配置、复杂创建、导入预览与确认。
- 结构：步骤与进度 → 当前步骤 → 上一步/下一步 → 最终确认 → 真实结果。
- 组件：Field、Progress、Alert、Table、Button、Dialog；步骤导航由语义有序列表与 Button 组合，shadcn 不假定提供内置 Stepper。
- 每步只问当前所需信息；可返回且保留数据；修改上游输入使依赖结果失效；导入显示有效/无效/重复项、范围和失败重试策略。
- 真正提交前说明影响；任务受理与完成分开显示；长任务使用后端任务状态，刷新后能恢复。

## 辅助页面与公共验收

登录/找回凭证使用品牌区 + 聚焦表单；403/404/维护页使用简洁状态说明与有效返回入口，不套业务表格。页面加载、无数据、无匹配、失败、无权、处理中、成功及冲突是模板的状态，不能只实现成功截图。

- 实现说明必须给出模板、布局与复用清单，差异有业务理由。
- 信息层级：第一屏能识别对象/任务、当前状态、主操作；不以装饰数量评价完成度。
- 桌面与窄屏、浅/暗主题、长文本、大数值、多语言、焦点和滚动均有设计；浏览器执行遵守当前 E2E 暂停规则。
- 行为验收：URL 直达/返回、筛选复位、错误重试、输入保留、重复提交、失效权限、无障碍名称与键盘路径。
- 本文是规范模板；可运行模板和视觉样板必须在实际实现后单独标注“已实现/已验证”。未安装组件不能当作已有接口导入。
