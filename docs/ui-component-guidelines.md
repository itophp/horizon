# shadcn/ui 组件使用与选型指南

源码提取见 [代码参考](code-reference/README.md)，AI 工作台与节点选型见 [AI 界面参考](ui-ai-patterns.md)。代码参考不注册演示路由、菜单或运行时翻译资源；AI 组合先查官方 AI Elements，不以通用 Card/Input 手工重造已有 AI 交互模式。

配套阅读：[组合与交互模式](ui-interaction-patterns.md)。该规范覆盖 Pagination、Navigation Menu、Popover、Radio Group、Toast、Hover Card、Dialog、Direction、Empty、Skeleton 的完整使用条件与验收，提供官方通用组件分类索引和业务组合配方。新页面与新交互先按用户意图选型，再复用原语和官方组合能力。

## 原则与官方能力复用流程

本项目使用 shadcn/ui **组件源码与交互能力**，不是仅使用其 CSS。业务页面必须优先导入 `@/components/ui/*` 或已基于其组合的共享组件；不得以原生 button/input/select/textarea、手写弹层或 div 点击区域加样式代替已有组件。组件内部的原生元素、语义化 main/section/form/label、Router Link、表格语义、文件输入等必要底层结构允许使用；不是禁止 HTML。

开发顺序：

1. 阅读本指南、[页面模板](page-templates.md)及本地 `components.json`，搜索现有 ui 原语与 feature/shared 组合能力。
2. 从 [官方 llms.txt](https://ui.shadcn.com/llms.txt) 找到所需组件、Forms、CLI、Theming、Registry、MCP 等官方入口，再读对应组件文档。索引是发现入口，不是完整 API，也不是本项目版本声明。
3. 优先复用本地组件；缺失时检索官方组件与组合示例、[Blocks](https://ui.shadcn.com/blocks)、[Charts](https://ui.shadcn.com/charts)。Blocks 用于借鉴结构并提取已有组件，不能整页复制带入第二套外壳、硬编码文案和业务请求。
4. 按本地 `base-nova` / Base UI 分支核对 API；不能照抄 Radix 的 asChild 或旧版示例。以本地源码和锁文件为编译依据，官网最新 API 不自动等于已安装 API。
5. 需要引入时用项目锁定 CLI：`pnpm --filter @baseline/web exec shadcn add <component>`；先审查文件覆盖、依赖、许可证、Base UI 兼容性与可见文案。升级或新增依赖同步 [版本记录](versions.md) / 必要决策，禁止用 @latest 绕过锁定版本。
6. 优先组合官方能力，再抽取真实复用的业务组件。只有官方与现有组合无法覆盖的部分才自建，记录缺口、替代方案与交互验收。

可用 shadcn MCP/Registry 搜索时复用；不可用时按官方文档与锁定 CLI 继续，不自动修改用户全局配置。不批量安装未使用组件，不为了“完全使用组件库”在页面堆满组件。

当前库存（2026-11-04 源码核对）：Badge、Button、Card、Checkbox、Dialog、DropdownMenu、Input、Select、Separator、Table、Tabs、Tooltip。PageHeading、DataTable、RowActions、EditorDialog 位于 administration/shared.tsx。AI 工作台表现层已进一步引入 Message、Bubble、Message Scroller、Trace、Collapsible、Input Group、Textarea、Empty、Skeleton；见 [AI 界面参考](ui-ai-patterns.md)。其余未在本地源码中的组件仍为选型目标，使用前需按流程引入。

## 按钮、命令和导航

| 场景 | 组件与变体 | 使用规则 |
| --- | --- | --- |
| 当前区域主要动作 | Button default | 一个操作区域通常一个高强调动作，名称是具体动词，如保存、创建；不能所有按钮同等突出 |
| 取消、导出、次要提交 | Button outline | 与主按钮同尺寸；不要每页重新写边框按钮 |
| 中性辅助动作 | Button secondary | 用于确需中等强调的动作，不和 outline 随意混用 |
| 返回、工具、行内入口 | Button ghost | 行操作多时复用 RowActions/DropdownMenu；关键操作不能仅悬停出现 |
| 删除、撤销等危险动作 | Button destructive + AlertDialog | 文案说明对象与后果；后端审批不被确认框替代 |
| 文本导航 | Router Link；需要按钮外观时按 Base UI 组合 Button | 保持链接语义、可复制地址与打开新标签；Button link 变体只定义外观，不能替代 URL 语义 |
| 多个动作集合 | DropdownMenu | 放“执行什么”，不能拿来代替业务字段选择器 |
| 相关动作并列 | ButtonGroup | 例如前后翻页；单选视图状态用 ToggleGroup，导航内容用 Tabs |
| 全局命令检索 | Command | 快捷跳转和动作搜索；不是默认业务远程选择器 |

尺寸以本地 Button 为准（Tailwind 默认 rem 下的近似像素值）：

| size | 高度 | 默认用途 |
| --- | --- | --- |
| xs / icon-xs | 24px | 高密度、低频内嵌辅助动作；避免触屏主要操作 |
| sm / icon-sm | 28px | 紧凑表格和次级工具 |
| default / icon | 32px | 页面工具栏、普通表单和弹窗 |
| lg / icon-lg | 36px | 聚焦表单或较舒展的主要动作 |

同一工具栏的输入、选择器、按钮采用同一密度；不用 className 随页覆写高度。移动/触屏应通过公共密度方案将交互命中区扩展到约 44px，不只放大图标。图标默认 16px（小按钮按组件缩放），来自 lucide；纯图标按钮必须有翻译后的 aria-label，Tooltip 只补充解释。主要动作优先图标加文字。

表单主操作显式 `type="submit"`，其余 `type="button"`。提交中保留动作含义，加入 Spinner，阻止重复提交；错误保留可重试入口。不要仅靠变灰表达进度。

## 字段与表单选型

| 输入语义 | 组件 | 约束 |
| --- | --- | --- |
| 单行文本、邮件、数值 | Input + Field | 使用合理 inputMode/type；金额与精度按业务校验，不能只依赖浏览器 number |
| 搜索、带单位/前后缀输入 | InputGroup + Input | 清除和搜索动作使用组件按钮；占位符不代替 label |
| 多行说明 | Textarea + Field | 预期行数、长度限制和错误明确；富文本另按实际需求选择引擎 |
| 2–5 个需同时比较的互斥选项 | RadioGroup | 简短且重要的选择优先直接呈现，不必藏进下拉 |
| 独立同意项、批量选择 | Checkbox | 支持全选/部分选中的准确语义；提交型表单布尔值通常用它 |
| 开关某项功能 | Switch | 适合启停；即时生效必须有失败回滚/反馈，统一提交时明确说明 |
| 连续范围调节 | Slider + 精确值输入 | 音量/阈值等；金额等精确数据不能只有拖动 |
| 日期、日期区间 | Popover + Calendar 的 Date Picker 组合 | 区间、禁选、清除、键盘输入和本地化明确；Calendar 不承担排班业务 |
| 时间/时区 | Input/Select/Combobox 组合 | 明确展示时区并按现有格式化和后端契约转换；不假定内置完整 DateTimePicker |
| 一次性验证码 | InputOTP | 允许粘贴与自动填充；不是密码输入替代品 |
| 文件与附件 | Button + 必要的隐藏原生 file input + 共享文件服务 | 类型/大小、上传进度、取消/重试、删除与权限校验；不虚构 shadcn 内置 Upload |

Field/FieldGroup/FieldLabel/FieldDescription/FieldError 组织标签、说明和错误；与 RHF Controller 及 Zod 配合，具体 props 按所引入 Base UI 源码核对。字段错误关联 aria-describedby/aria-invalid；错误不改控件可访问名称。必填、禁用、只读、加载、无权语义分开；业务服务端验证仍是最终依据。

## 下拉选择决策

### 关联数据展示规则

关联对象在列表、详情、卡片、标签、表单回显、筛选条件、审批、通知与批量结果中，必须显示用户能识别的名称、标题或其他授权的业务标识；内部 ID 只用于稳定关联、请求参数和组件 key，不作为用户可见内容或显示失败时的回退。用户确需操作的业务编号可以作为辅助信息，但不能代替名称或暴露内部 ID。

| 关联类型 | 展示方式 | 交互与边界 |
| --- | --- | --- |
| 人员 | Avatar + 姓名；同名时补充经授权的账号或部门 | 头像缺失显示安全的名称缩写或默认图标；详情入口须有权限 |
| 项目、组织、部门等对象 | 名称/标题；必要时附经授权的业务编号或上级名称 | 用文本或可访问链接，不能显示原始关联键 |
| 多个关联对象/数组 | 每项展示名称；人员可用头像组 + 名称列表 | 较多时展示前几项及本地化剩余数量，提供键盘可访问的完整列表；不得只显示头像或 ID 数组 |
| 多级关联 | 显示授权的层级名称或路径 | 层级中无权内容使用不泄露信息的占位，不拼接未授权名称 |

优先让现有授权的列表/详情能力直接返回所需展示投影；否则通过已有授权查询能力批量解析，复用生成 SDK 与 TanStack Query。不得每行无界发起请求、在前端自行关联全租户数据或扩大字段范围；批量查询和缓存仍按账号、租户、部门及语言隔离。缺少授权的展示投影时先按能力与契约规则补齐，不能退回显示 ID。

加载中用本地化加载状态或 Skeleton；无关联、已删除、停用、无权查看和查询失败按服务端允许公开的语义区分，失败提供适当重试。不允许因为名称不可见而推断对象存在、泄露其名称或 ID；无权与不存在需合并时由服务端语义决定。头像及其他附件遵守共享文件授权，不直接拼接未经授权的文件 URL。文本、剩余数量、辅助名称和状态均走 i18n；长名称可截断，但必须提供键盘可访问的完整内容。

验收覆盖单值与数组、同名对象、头像缺失、长名称、加载/失败、空关联、删除/停用、无权、切换身份后的缓存隔离，以及无任何内部 ID 泄露到可见内容。关联选择仍按下节使用远程搜索，服务端继续验证实际 ID 和权限。

### 关联对象选择强制规则

关联对象是有独立身份和生命周期的业务实体，如账号、部门、组织、客户、项目、成员、文件及其他记录。凡由用户指定此类对象，不论单选、多选、级联、批量操作、筛选或弹窗，都必须通过**服务端授权范围内的远程搜索与选择**完成；即便当前候选很少也不改成静态列表。禁止把内部 ID 输入框、可自由输入的文本框、手写 ID 占位提示或一次拉全量再本地搜索当作关联选择器。用户可按名称、编号等业务信息搜索，但只能从返回的合法候选中选择，表单内部保存并提交稳定 ID。固定枚举、布尔开关和不指向独立业务实体的静态选项不受此规则限制；字典若承载关联实体，仍遵守本规则。

- 单选或多选优先使用受控 Combobox；需要呈现组织树或复杂关系时用 Dialog/Sheet + 支持服务端搜索的树/列表与已选摘要，且同样不得只加载全量树到客户端搜索。组件原语缺失时按锁定版本安装并核对兼容性，不用原生 ID 输入降级。
- 查询优先复用现有能力、授权数据范围及生成 SDK；缺少搜索或回显接口时，按能力组合、服务端授权、契约生成及实体规则补齐后再交付选择器。不得绕过 Gateway、裸 fetch 或扩大查询权限。
- 编辑时用授权详情查询回显已有 ID 的名称；不可见、停用或删除的历史关联以服务端允许的脱敏状态明确展示，避免泄露名称，也不能静默清空或当作合法新选项提交。必填、清除、可保留历史值的语义由业务规则决定。
- 搜索要处理防抖、输入法、分页、请求取消和乱序，区分未输入、加载、无匹配、失败和无权限。候选展示足以区分同名对象的信息，并按账号/租户/部门/语言隔离缓存。
- 上游关联变化时取消旧查询，清除或重新验证下游选择；选择后的对象可能被删除或撤权，提交时服务端仍须验证存在性、租户、数据范围、关联关系和当前权限。无权限或无结果不得提供直接输入 ID 的旁路。
- 验收覆盖：真实远程查询和服务端范围、同名区分、单/多选、编辑回显、失效和越权、请求乱序、级联变化、切换身份、键盘及失败重试。没有后端搜索能力时明确列为未完成，不以静态假数据或输入 ID 交付。

| 需求 | 首选 | 不应采用 |
| --- | --- | --- |
| 少量稳定、无需搜索的单选值 | Select | 原生 select 加样式，或 DropdownMenu 模拟表单字段 |
| 需横向比较的少量互斥选项 | RadioGroup | 所有选择都塞进 Select |
| 本地较多选项、按名称搜索 | Combobox | 在 Select 弹层里硬塞 Input 并自行拼键盘逻辑 |
| 远程账号、客户、字典搜索 | 受控 Combobox + TanStack Query + 生成 SDK | 一次拉全库、页面 fetch、把远程搜索交给纯本地过滤 |
| 多选且可搜索 | Combobox 的 multiple/chips 能力（核对本地 API） | 多次单选拼接字符串；用 Badge 假装完整多选交互 |
| 少量可见多选 | Checkbox 组 | 不必要的可搜索弹层 |
| 操作菜单、更多命令 | DropdownMenu | Select/Combobox 混淆“动作”与“值” |
| 切换内容区域或子页面 | Tabs | 把当前页导航伪装成表单选择值 |
| 复杂组织层级、跨级多选 | 由 Dialog/Sheet + 树/列表 + 选中摘要组合的共享选择器 | 无限嵌套 Select，或假定 shadcn 自带完整 TreeSelect |

选项数量只是判断依据；名称相似、远程数据和搜索习惯比固定阈值更重要。原生 NativeSelect 虽然在官方库中存在，本项目新业务页面默认使用 Select；只有明确的平台约束才记录例外。

### 远程搜索的完整行为契约

共享远程选择器可在出现真实复用时抽取，但业务 API 与权限留在 feature/数据层。不得在 ui 原语中内置某个客户或账号接口。

1. **状态分离**：`value` 保存稳定 ID（多选为 ID 列表），`inputValue` 保存正在输入的搜索词；选中项 ID/标签和查询结果分别管理，不能用名称充当主键。
2. **触发策略**：通常约 300ms 防抖，支持中文输入法组合输入完成后查询；最小字符数和是否加载最近项由数据量/接口能力决定，并提示“请输入关键词”。焦点、下拉打开和选择后的查询行为明确。
3. **请求隔离**：Query key 包含可信账号/租户/部门上下文、语言、依赖字段、搜索词及分页；通过生成 SDK 请求并利用 AbortSignal 取消旧请求。UI 只渲染当前 key 的结果，慢响应不得覆盖新词结果。
4. **服务端搜索**：后端负责搜索、排序、范围和分页；按 Combobox Base UI 的受控过滤 API 禁用二次本地过滤，不能假定 Command 的 `shouldFilter` 可直接用在 Combobox。避免按显示名称过滤掉服务端按编号命中的结果。
5. **状态呈现**：未输入提示、首次加载 Spinner、已有结果刷新、无匹配 Empty、失败 Alert/重试、无权/依赖未选分别呈现；无结果不等于请求失败。不要把“加载中”伪装成可选业务项。
6. **分页与性能**：限制每页结果，按能力使用加载更多或分页；去重保持稳定顺序。虚拟化只有测得必要才引入，并验证活动项与屏幕阅读器语义；不能拉取全量敏感目录到浏览器。
7. **标签回显**：编辑页通过授权详情接口回填已选 ID 的标签，选中项不因搜索翻页消失；失效/被删除选项明确标记。身份或数据范围改变时清空旧私有缓存和标签，不展示前一身份数据。
8. **选择与清除**：Enter 选中活动项、Esc 收起、焦点返回；清除是否允许按字段必填决定。多选支持移除和键盘行为，不能用颜色单独表达已选。
9. **级联依赖**：上游改变取消旧请求，清空或重新验证下游 ID；提交前继续由后端验证关联与授权。不可保留旧组织下的有效外观选项。
10. **创建新项**：只有业务确有创建能力与权限才出现“新建”，走 Gateway；搜索框自由输入不自动变成合法实体 ID。

最低交互验收：中文输入、防抖、请求乱序、失败重试、无结果、回显未在当前页的选项、清除、多选、上游变化、切身份和键盘路径。文档规定不等于这些交互已经实现。

## 容器、导航与浮层

| 组件 | 什么时候使用 | 边界 |
| --- | --- | --- |
| Card | 一组有独立语义、标题/操作的内容 | 不给每行或每个字段套卡片，不连续嵌套 Card |
| Tabs | 同一对象下切换内容视图 | 可直达时同步 URL；不同业务对象可用子路由，不堆无限标签 |
| Accordion / Collapsible | 多组次要详情 / 单块可折叠内容 | 不默认隐藏关键错误、必填字段和主要动作 |
| Breadcrumb / Sidebar | 层级路径 / 应用导航 | 保留现有菜单与 shell；不直接用 Blocks 替换已确认外壳 |
| Separator | 分隔相邻内容组 | 优先留白形成层级，避免每行画线 |
| Dialog / EditorDialog | 短、聚焦、需要完成或取消的任务 | 超长多分组表单升级独立页面；详情复杂时走详情模板 |
| AlertDialog | 明确后果的危险确认 | 显示对象、影响、取消和具体动作；不用 window.confirm |
| Sheet | 桌面侧向预览、辅助编辑、窄屏筛选 | 需要上下文时使用；复杂长任务仍走独立页 |
| Drawer | 有明确移动端底部抽屉需求 | 先核对 Base UI 与附带依赖兼容性；不是 Sheet 随意改名 |
| Popover | 日期选择、小型筛选等局部交互 | 不承担复杂表单与多层业务流程 |
| Tooltip | 图标含义和短辅助提示 | 关键内容、错误与必读说明必须直接可见；触屏有等价入口 |
| HoverCard | 对象的补充预览 | 不把必要操作只藏在 hover 内 |
| Resizable / ScrollArea | 可调工作区 / 确需定制的局部滚动 | 默认用正常布局与 overflow；不要层层包 ScrollArea |
| ContextMenu / Menubar | 画布/编辑器的辅助命令 | 右键与快捷键必须有可见菜单替代，普通管理页不滥用 |

浮层须保留标题/描述、焦点约束与返回、Escape/关闭策略、表单错误和未保存提示；嵌套选择器优先在当前弹层完成，不堆多层 Dialog。不能在 Router Link 内再嵌套 Button。

## 数据展示、反馈与媒体

- **Table + TanStack Table**：比较结构化记录；用项目 DataTable 承担状态、列、排序筛选与分页。官方 Data Table 是组合方案，不是可直接假设存在的成品组件。金额/数量靠右、单位明确，主名称链接靠左；长文本截断并提供完整内容入口，日期用 lib/format。行高紧凑建议 36–40px，普通 44–48px，在公共密度中统一；不要为塞下全部字段无限缩小字号。
- **Badge**：状态、类别、数量摘要；颜色有语义 token 且同时有文字。状态不假定官方已提供所有 success/warning 变体，需按本地源码统一扩展。
- **Item / Avatar**：通知、资源、人员摘要；头像有回退，图片失败不破坏布局。**AspectRatio** 用于封面比例。**Carousel** 仅用于确有顺序浏览需求的媒体，不用来藏关键企业指标。
- **Skeleton**：结构可预期的首次加载；**Spinner**：按钮或局部请求；**Progress**：有真实总量的进度。未知进度显示阶段/处理中，不生成虚假百分比。
- **Empty**：无数据与无搜索结果分别给创建或清除筛选入口；**Alert**：持续可见的错误、风险、操作结果；**Sonner/官方 Toast 路径**：短暂成功或非阻塞反馈，安装前核对官方当前实现，不并行引入两套 Toast。字段错误不能只用 Toast。
- **Typography / Kbd**：正文排版与快捷键说明；标题保留 h1/h2 等语义，不能以字重代替层级。Markdown 的排版方案沿用现有安全渲染，不能因官方 Typeset 示例而启用危险 HTML。

## 图表选择与实现

优先复用官方 Chart、Charts 示例及 Recharts 组合；当前未安装 Chart，接入时先核对锁文件和官方版本。官网 2026-11-04 的 Chart 文档使用 Recharts v3，不能把其代码直接套到其他主版本。

| 用户要回答的问题 | 图形 | 选择依据 |
| --- | --- | --- |
| 当前多少、与目标/同期差多少 | 指标文字 + 差异说明，必要时迷你趋势 | 单个数字不必强行画仪表盘 |
| 随时间怎样变化 | 折线图；确需强调累计量时用面积图 | 时间轴按真实间隔；缺失值不当零，序列多时可筛选 |
| 类别之间谁高谁低 | 柱状图；长名称/排名用水平条形 | 柱轴通常从零起，避免夸大差异 |
| 总量由哪些部分组成 | 堆叠柱；比较占比用 100% 堆叠柱 | 数量与百分比不混淆；类别太多先分组或转表格 |
| 单个时点少量组成占比 | 环形/饼图 | 建议 2–5 类且有共同总量；精确比较优先条形；无总量不绘制占比 |
| 两个数值变量的关系 | 散点图 | 明确单位、样本量；相关性不写成因果 |
| 数值如何分布 | 直方图/箱线图 | 先核对 Chart/Recharts 支持；分箱范围明确，必要时专门组合 |
| 是否达到目标、执行多少 | Progress + 目标/当前数值 | 不能用环图混淆“占比”与“完成率” |
| 查精确值、很多系列或很稀疏的数据 | Table | 不必为了页面多样化一定画图 |

统一约束：

- 使用 ChartContainer、ChartTooltip/ChartTooltipContent、ChartLegend/ChartLegendContent 等官方能力，业务只组装数据与图形，不重写一套 tooltip/legend；给容器可测量的高度或 min-height，避免首屏尺寸为零。
- 复用 chart 语义颜色 token，同一指标跨图保持颜色；浅/暗可读，不只依赖颜色，必要时补线型、标记或直接标签。
- 标题说清问题，显示时间范围、单位、粒度、时区、数据更新时间及比较口径。默认避免 3D、无意义渐变、双 Y 轴和过多序列；比例必须有分母。
- 默认主图高度约 280–360px、小图约 180–240px，作为公共模板参数集中定义；窄屏减少刻度，不压扁成无法阅读的装饰。
- 开启所用图形支持的无障碍能力；提供文字摘要与授权数据明细入口，关键数值不能仅 hover 才可见。
- 首次加载、无数据、全部为零、部分缺失、刷新失败分别处理；服务端负责授权聚合，前端不拿无权明细自行计算。
- 官方示例数据、英文文案、颜色和随机数不能进入正式页面；图表筛选与数据范围共用 Query/URL 规则。
