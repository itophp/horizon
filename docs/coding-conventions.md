# 编码约定

TypeScript strict；禁止显式 any。未知输入使用 unknown 并在边界检查。API DTO 与 hooks 由 Orval 生成，UI 不重复声明。前端 Zod 不能代替服务端校验：Goa DSL 对参数执行长度/范围校验，SQL 再约束持久化输入。

Go 使用小接口隔离依赖；errors 向外映射稳定码，不把数据库内部错误返回用户。请求日志避免凭证、请求参数和响应正文。所有错误必须处理或返回。HTTP 有读写/空闲超时及请求体限制，客户端有超时与取消。

prettier 与 gofmt 统一格式。以用户可见行为测试交互；生成代码只验证可重复性、编译与集成，不逐行测试。优先 role/label 定位；失败保存 Playwright screenshot、trace 及网络/控制台诊断。

新增文件优先放入明确模块，不新建空业务目录。公共组件修改前查调用方。按用户当前需求持续开发，不擅自添加无关业务或替换技术栈。
