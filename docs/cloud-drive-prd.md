# 企业云盘产品需求与一期技术方案

状态：需求及方案草案；一期功能尚未实现或验收。

## 目标与范围

为企业员工提供内部文件存储和协作空间，支持个人空间、共享空间和多级文件夹。首期单个文件不超过 1 GiB，回收站保留 60 天。不包含外部分享、预览、在线编辑、版本历史和全文检索。

## 角色与权限

| 操作 | 个人空间所有者 | 共享空间管理员 | 编辑者 | 查看者 |
| --- | --- | --- | --- | --- |
| 浏览、搜索、下载 | 是 | 是 | 是 | 是 |
| 上传、整理、删除、恢复 | 是 | 是 | 是 | 否 |
| 成员及空间管理 | 不适用 | 是 | 否 | 否 |
| 提前永久删除 | 是 | 是 | 否 | 否 |

个人空间首次访问时按租户与账号幂等创建，仅本人可访问。取得创建权限的员工可创建共享空间，创建者自动成为管理员；共享空间必须保留至少一名有效管理员。授权可针对账号或部门，当前有效归属内的多条授权取最高角色，系统显式拒绝优先。撤权后后续请求立即重新授权，包括未完成的上传。离职后个人空间不自动开放；共享空间异常交接由管理员治理处理。

## 功能与规则

- 空间内支持文件夹创建、浏览、路径导航、重命名、移动和删除，以及文件上传、下载、重命名、移动和删除；支持名称搜索、类型筛选与排序。
- 同一目录下同类型对象不得重名；文件与文件夹可以同名。禁止跨空间移动，禁止目录移入自身或后代。
- 支持多文件上传、进度、重试与续传。单文件默认最大 1 GiB，具体类型限制由管理员配置；下载以附件形式处理，不使用文件名构造服务器路径。
- 删除目录时整棵子树作为一个删除批次进入回收站。服务端按删除时间保留 60 天；管理员或个人空间所有者可提前永久删除。恢复时原位置不存在或重名，要求用户选择有效位置或修改名称。
- 记录上传、下载、移动、删除、恢复和授权变更等操作；审计不得包含文件正文、凭据或存储路径。管理员可配置容量，默认不设业务额度，仍受实际存储容量限制。

## 技术方案

空间、成员授权、目录、文件关联、上传会话、分块和删除批次分别持久化；所有业务表带租户标识及租户复合外键。目录采用父节点关系，移动时锁定相关节点并检查祖先关系。文件引用现有文件记录及其不可变存储 profile，云盘访问由空间绑定授权，不扩大既有附件或品牌文件权限。

独立动作在业务模块注册能力，通过 Gateway 完成身份、权限、Schema、风险、幂等及审计。数据库原子写能力采用 TxExecutor，业务状态与 Outbox 同事务；能力组合只能通过 Gateway，事务执行器内不调用 Gateway。个人空间初始化、成员管理、目录和文件动作、上传会话、分块、下载、回收站及清理均须覆盖能力契约和实体状态声明。

上传使用有界分块，单块原始内容上限 4 MiB。开始会话时固定租户、发起人、空间、目标目录、名称、大小和存储 profile；会话默认 24 小时过期。顺序上传的每块记录序号、长度和摘要，重试按序号幂等。完成时重新授权，流式计算完整大小及 SHA-256，提交文件关联和成功事件，再清理临时分块。文件对象和数据库不能组成单一事务：临时对象不可公开，失败、崩溃及重复提交须有持久化、可重试的清理和恢复机制。

下载先读取授权元数据，再按偏移有界读取；每次读取重查空间权限。若浏览器无法以有界内存可靠保存 1 GiB 文件，须实现经 Gateway 授权的流式响应适配并验证。禁止把文件内容放入调用日志或审计投影。

到期回收站及过期上传使用系统身份经 Gateway 分租户、分批处理，以条件更新和数据库锁避免多实例重复处理。永久删除先记录意图，再删除对象，成功后标记完成；失败保留重试记录，恢复与清理互斥。监控清理积压、失败、上传失败和存储容量。

前端复用生成能力 SDK、TanStack Query/Table、React Hook Form 和 Zod；提供空间、文件列表、路径、上传进度、成员和回收站界面。用户文案同时维护英文和简体中文。新增配置复用系统设置；不直接访问磁盘或绕过 Gateway。

## 验收

- 不同租户、非成员和已撤权用户不能通过列表、搜索、直接 ID、上传或下载访问文件；个人空间仅本人可见。测试账号和部门多重授权、显式拒绝及最后管理员保护。
- 测试多级目录、重名、循环移动、删除子树、恢复冲突及 60 天到期，并验证恢复与清理并发。
- 测试空文件、1 GiB 边界与超限、错误摘要、重复分块、断线续传、会话过期、重复完成、重启及存储失败；验证下载完整性。
- 在隔离 PostgreSQL 中验证迁移、实体、租户约束、事务及 Outbox；执行生成检查、规则检查、集成、安全和 ci-fast 检查。全量浏览器 E2E 按仓库当前指示暂停。

## 后续规划

文件版本、更多格式预览、批量下载、外部分享、全文检索和在线编辑另行设计，尤其需要重新评估授权、存储成本和信息安全。
