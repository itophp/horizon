# 制造型 ERP 前端演示

选择一个场景覆盖较广的系统：制造型 ERP。以销售→计划→采购→入库→领用→对账为业务链，不同时搭建独立 MES/HRM。

使用者：采购、仓储、生产计划与财务人员；首先关注异常与待办，再进入具体单据。

布局：ERP 工作台包含经营总览、采购协同、库存管理、生产计划、财务对账五种视图。总览采用指标带+趋势/待办+异常表；采购采用筛选+单据表+Sheet主从详情；库存采用库区导航+库存表+预警；生产采用产线卡与工单排程；财务采用账龄分析+对账清单。现有八类页面模式作为基础参考保留。

组件：复用 shadcn Tabs/Card/Badge/Select/Table/Progress/Sheet/Dialog/Input/Checkbox/Alert；同一单据预览用明细、流转、附件标签，不混入无关常驻表单。

交互：业务视图切换、查询筛选、仓库范围、单据预览、数量与金额核对、模拟确认与状态更新。所有金额和指标都是固定本地样本，不接入 Runtime、API、数据库或真实财务行为。

验收：五个ERP视图、单据Sheet与模拟确认；1440/768/390、浅暗与双语。最新结果在交付时追加，不沿用此前通用页的验收结果。
