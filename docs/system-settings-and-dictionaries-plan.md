# 系统设置、字典管理及通知附件能力正式开发方案

状态：已批准执行；配置范围设计已由用户最新要求及 [ADR 007](decisions/007-global-governance.md) 调整为公共设置/公共字典，无企业/公司/部门关联；实现与实际验收结果分别记录于代码和 [verification.md](verification.md)。本方案取代此前草案中的待定选项，不以文档存在代表验收完成。架构决策见 [ADR 005](decisions/005-system-governance.md)，通知中心与人工 Markdown 消息扩展以 [ADR 008](decisions/008-notification-center.md) 为准。

## 交付目标与技术边界

在既有 Goa → OpenAPI/Orval、sqlc/pgx/PostgreSQL、React/shadcn、TanStack Query/Table、React Hook Form/Zod、i18next 框架上实现真实保存、发布、生效及追踪。后台沿用现有侧栏包裹内容面板、正文独立滚动、中性浅暗主题与中英文，不引入另一套 UI 或第二套身份授权。

通知为站内消息及 SMTP 邮件，覆盖临时权限申请、批准、拒绝及审批人撤销；本人撤销不重复通知本人。附件本次仅实现服务器私有目录。存储通过驱动注册接口扩展，只注册 local；不实现第三方存储或自动迁移。新文件绑定新配置，旧文件仍从上传时的配置版本读取。

发布、回退、导入导出、文件管理及投递管理独立授权。敏感发布和所有回退重新认证，凭据绑定会话、当前部门、动作、资源及版本，五分钟单次有效；不增加双人审批。

## 系统设置

注册表定义稳定键、分组、类型、默认值、允许层级、枚举、上下界、敏感性及实际消费者，禁止任意配置键。支持显式空值、false、0，恢复系统默认值使用独立操作。秘密值用环境根密钥 AES-GCM 加密；查询、历史、差异、导出和日志不返回明文或密文。

系统参数统一由工作空间管理，不选择企业、公司或部门范围；展示/通知白名单可由本人偏好覆盖。品牌、SMTP、上传限制等公共配置统一生效，个人偏好不能覆盖安全或存储参数。

系统公共配置经过草稿、校验、变更预览、发布，版本号检测并发；同一事务提交覆盖值、版本和脱敏审计。回退重新校验当前定义并生成新版本。个人白名单偏好直接保存；页面展示默认值、当前值、最终值、版本及待发布记录。

| 分组 | 实际消费者与默认行为 |
|---|---|
| 品牌 | 登录与后台名称、副标题、登录标题/描述、提示、联系与页脚、已发布 Logo；公开读取仅使用部署绑定工作空间白名单 |
| 显示 | en 回退、dark、Asia/Shanghai、日期格式、24 小时制、数字分组、每页 8 条；个人服务端值优先，旧浏览器偏好只用于首次迁移 |
| 账号安全 | 密码至少 12 字符，可要求大小写/数字/符号；5 次失败锁定 15 分钟；会话绝对 480 分钟、空闲过期 0（关闭）；新账号默认 active |
| 临时策略 | 可选原有租期集合、最大 10,080 分钟、原因至少 5 字符；影响后续申请/审批，不重写既有批准租期 |
| 邮件 | 启停、白名单主机、端口、TLS/STARTTLS、用户名/密码、发件人、双语纯文本模板、连接测试和本人邮箱测试发送 |
| 存储/上传 | local、允许根目录下的相对目录、应用文件访问地址前缀、上传大小及扩展名限制 |
| 个人通知 | 站内及邮件偏好，消息仍按接收账号和部门隔离 |

密码新策略只约束新建/重置。会话收紧可提前结束旧会话，放宽不延长已签发到期时间。正式授权、禁止自批/再委托、固定 deny、部门隔离等安全不变量不允许通过配置关闭。

## 字典管理

定义具有分类、全租户唯一稳定编码、双语名称、拥有层级、flat/tree/dynamic 类型、启停、可见性、附加消费权限及是否允许扩展。静态项具有稳定 ID/代码、双语标签/说明、父代码、排序、默认、状态、有效期及受约束 color/icon 属性。关键权限/账号/审批枚举继续由 Goa 契约维护。

字典为工作空间公共定义，不选择组织范围，不维护本级覆盖或部门扩展。已发布项不能物理删除或改码，归档/停用后不能新选，但历史 ID 仍可解析，业务无关字段编辑可保留原引用。

树校验同租户、同字典、可见父级、重复代码、最多 16 层、循环及默认唯一性；父项无效时后代不可新选。公共选项统一可用；动态提供器仍保留原资源权限。回退保留后续新增的稳定项并归档，避免破坏历史外键。

CSV/JSON 导入限制 10 MiB、10,000 行，先预校验、错误定位和差异，再生成草稿，最后独立发布。导入不改变字典元数据或稳定 ID；导出 CSV 转义公式，并带版本标记支持安全往返。动态字典禁止静态项导入导出，受控提供器仅允许组织、部门、角色、账号，复用原资源授权与数据范围，只返回选项字段；不接受任意 SQL/URL。

运行时选项接口按当前上下文和语言解析；编辑历史引用通过明确 ID 请求。业务持久化使用 `dictionaries.Service.ReplaceReferences`，调用方先在原业务权限/范围内加载拥有记录，再在同一事务传入可信原引用，不能把客户端旧引用当作可信依据。

## 附件与存储

默认普通附件 20 MiB、Logo 2 MiB。Logo 仅 PNG/JPEG，校验像素数并重新编码；普通附件默认 PNG/JPEG/WebP、PDF、文本、CSV、DOCX、XLSX，校验扩展名与实际内容。上传 JSON base64 有独立有界请求体和超时，普通 JSON 仍限制 1 MiB。

部署指定绝对允许根目录；设置只接受其内相对目录。使用租户隔离目录与服务端随机键，原始名称只作元数据。使用 os.Root 限制路径和符号链接越界，临时写入后原子重命名，失败清理可观测。

文件绑定不可变 driver/config-version/key，存储配置被引用不能删除。驱动接口声明可写能力、受控配置字段以及 Validate/Write/Read/Delete/Probe；未注册驱动不可发布。历史配置按原版本解密及读取，不自动搬迁。删除先软删除，再由受控后台清理物理文件；品牌历史绑定阻止删除仍被引用的 Logo。

私有附件从应用鉴权入口下载，访问地址生成 `/files/:id` 应用链接。公开 Logo 仅通过部署绑定的已发布品牌入口提供，已登录上下文 Logo 只读取自身有效品牌，不能公开整个目录。附件页面和真实下载接口同时校验 files:read 及 SQL 范围。

## 通知与投递

临时权限状态变化通过 PostgreSQL 事务事件记录，队列使用租约和唯一键恢复、去重。申请发送到具有正式 temporary:approve 的有效部门上下文，批准/拒绝/审批人撤销发给申请部门的本人。

站内消息绑定 tenant/recipient/department，邮件投递前重新检查账号、归属、审批能力及渠道偏好。无邮箱、配置关闭或权限撤销具有独立脱敏结果代码；站内消息不依赖邮箱。SMTP 使用经过部署白名单的主机、验证证书的 TLS/STARTTLS、超时、纯文本双语模板、稳定 Message-ID、最多五次指数退避重试；失败可按独立正式权限人工重试。外部邮件属于至少一次投递，不承诺绝不重复。测试仅允许显式测试选项和字面 loopback 的隔离服务器跳过 TLS。

独立通知菜单及顶部铃铛进入通知中心（收到、发起、已发送、投递记录）；SMTP/模板配置在系统设置，连接/本人测试发送和投递记录在通知中心。人工通知可混选账号、部门（含子部门）、公司、企业，服务端按正式范围展开去重，支持 Markdown 及绑定私有文件，按 ADR 008 进行幂等、事务和收件人文件鉴权。测试发送只能发到操作者已保存的邮箱，不接受任意收件地址。

## 权限、数据与实施

设置、字典、文件、通知分设 Goa 服务，共用 identity.Authorize/ScopeFor、Principal、Casbin 和 SQL 范围，不复制登录。新增 system 一级模块，二级为 settings/dictionaries/files/notifications；原有角色不因通用规则或目录增长自动获得新权限，内置管理员保持隐式全权。管理写、发布、回退、导入导出和投递管理使用正式授权；files:read、dictionaries:use 可按目录允许临时申请。

设置/字典管理使用工作空间共享 owner 和 ALL 范围，不套用“账号任意部门可见”。个人偏好/消息无需管理权限，字典消费使用明确的 use 及原资源权限。每个查询、详情、导出、删除、关联、后台任务及下载均执行可信租户与相同范围。

追加迁移保存 scope/revision/value、草稿/版本/脱敏审计、字典/项/历史覆盖/引用、文件/配置/绑定、事件/消息/投递及单次重新认证凭据，保留既有账号、会话和授权。Goa/SQL 源生成全部 SDK 和 dbgen；JSON bytes 在 Orval 输入适配中按真实 base64 传输生成 string 类型，不手改生成物。

实施顺序：文档/契约/权限/迁移 → 设置及消费者 → 字典及导入导出 → 本地附件及 Logo → 消息/SMTP/临时事件 → 联调、规则同步、开发迁移和验收。

## 验收

覆盖多公司/多部门切换时公共配置/静态字典一致、个人偏好独立、消息与动态数据缓存隔离；旧组织目标拒绝、显式空/false/0、恢复、并发冲突、原子发布、单次重新认证、回退；稳定代码、树环、禁用历史、动态越权、导入绕过；文件超限/伪类型/越界/越权/失败清理/存储切换；事件幂等、SMTP 失败重试、撤权、无邮箱、缺配置、脱敏；中英文、浅暗主题、键盘、空/错状态、刷新保持。

运行 make ci-fast、make test-security、隔离真实 PostgreSQL 及 make ci。SMTP 用隔离服务器、文件用临时目录。实际管理员邮件凭证仅在系统设置输入，不在对话、日志或仓库提交。验收记录区分已执行本地结果、未执行项、外部环境限制和远程 CI 状态。

系统设置定时发布按 [ADR 010](decisions/010-settings-schedules.md) 扩展：草稿可一次性排期、取消与追踪，复用正式发布权限和敏感单次证明，到期重新校验原身份、范围、依赖及版本后原子发布；不改变个人偏好即时保存或字典发布流程。
