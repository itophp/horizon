# 基础安全与授权规则

本规则适用于所有功能，新增能力时按实际威胁边界选用，不等于已经完成生产认证或安全审计。

## 必须保持的边界

| 控制点 | 本项目实施位置 | 开发时必须考虑 | 验证 |
|---|---|---|---|
| 身份可信 | internal/identity，Principal，transport | 凭证/会话验证、默认拒绝、身份上下文，不能信任客户端 tenant/owner | 会话与 HTTP 拒绝用例 |
| 操作授权 | internal/identity（Casbin model/policy） | 资源/操作、租户域、失败拒绝、撤销/缓存/跨实例失效语义 | RBAC 允许/拒绝、即时撤销 |
| 数据范围 | dataaccess + repository + 参数化 SQL | 所有访问入口一致，租户条件永远保留，单记录写入原子约束 | 隔离 PostgreSQL 的五类 scope 与越权 ID |
| 字段保护 | Goa Result/Payload + SQL 投影 | 读写白名单、敏感新增字段、导出与日志；不能只靠 UI 隐藏 | 响应投影和敏感字段负向用例 |
| 输入和资源限制 | Goa 验证、应用不变量、DB 约束、HTTP 超时/体积 | 公开接口理由、未知字段/文件/路径等新外部输入、事务边界 | 无效输入、约束与配置测试；新增入口补特定用例 |
| 凭证与错误/日志 | config、.env.example、统一 client/transport | 不提交真密钥，不把 token 放 URL/持久化浏览器存储，不返回 SQL/堆栈，不记敏感正文 | 配置负向测试、diff/日志审查 |
| 浏览器安全 | 同源代理、统一 request | CORS/cookie/CSRF 按认证设计决定，避免通配来源或未经评估的 cookie 组合 | 与选定认证方案匹配的请求/浏览器测试 |
| 依赖和生成链 | 锁文件、DSL/SQL/生成器 | 核对官方版本、兼容性、许可证与维护性；不靠生成代码补丁绕过边界 | 类型/静态/生成一致性及变更审查 |

新功能在实现前明确 resource/action/scope/字段与公开性；新增导出、批量、聚合、下载和后台任务不是授权例外。SQL 不能接受前端提交的范围字符串作为权限来源。

## 当前实现与未启用能力

正式后台已实现数据库账号、Argon2id 密码、默认 8 小时 HttpOnly/SameSite=Lax 会话、令牌摘要、同源 Origin + CSRF、登录限流、停用及密码重置撤销。COOKIE_SECURE=false 仅用于数字 loopback 开发；其他监听要求开启 Secure 并通过 HTTPS 访问。初始密码由操作者显式提供，初始化不能覆盖已有工作区。完整边界与合并规则见 [身份决策](decisions/002-identity-access.md)。

正式 IAM 每个请求读取活跃账号、公司、企业、部门、角色与覆盖策略，没有授权决策缓存。角色权限合并，账号 allow 替换同操作继承范围，deny 拒绝。支持 ALL/ORGANIZATION/DEPARTMENT/DEPARTMENT_TREE/OWN/CUSTOM，SQL 保留 tenant 条件；结构更改校验公司关系、树环和引用。权限管理需额外 access:manage；它是整个工作区的授权管理能力。

开发 token 仍默认关闭，仅保护独立技术 demo，不能作为正式后台凭证。SSO/OIDC、MFA、自助邮箱找回、长期合规审计存储与分布式来源限流尚未提供；现有业务版本/审计及结构化日志不提供长期归档和防篡改合规留存。RLS/OpenFGA 未启用；引入时必须按真实应用数据库角色验证。

## 检查方式

`make test-security` 是可执行入口：认证、配置、RBAC/scope/HTTP 与真实数据库范围的允许/拒绝测试。完整 CI 也运行同一批用例。它验证已有控制点，不自动涵盖未来新增接口；新增能力要扩充测试。

字段分类、公开端点合理性、认证/CSRF/CORS 设计和日志敏感性需审查；本项目没有用脆弱字符串 grep 冒充完整密钥扫描或安全审计。当前未接入依赖漏洞数据库/专用密钥扫描服务，发布策略需要此类工具时再明确选型、版本和失败规则，不把未启用检查写成通过。

临时授权在正式策略基础上补充允许和范围，显式 deny 优先。独立审批、正式权限上限、禁止自批、固定范围、数据库时间过期和原子状态转换见 [ADR 003](decisions/003-temporary-access.md)。修改审批、会话解析或数据范围不能只测长期角色权限，还需运行 temporary_access_test.go 的真实数据库用例。


任何认证、权限控制或数据范围行为变更，必须同步维护权限控制相关的 Skill、目录 AGENTS.md 和安全/架构规则，并补齐受影响的允许与拒绝测试；交付说明列出同步位置，不允许只改代码。

多部门授权以 [ADR 004](decisions/004-department-memberships.md) 为准：当前部门验证、角色/覆盖隔离、正式范围保护持久授权、任意归属 SQL 过滤及临时权限部门绑定缺一不可。不得合并跨部门授权或以 OWN/临时权限写入另一部门的持久策略。


内置管理员账号仍禁止停用、删除及移动受保护主部门；界面中主部门策略的锁定不能连带隐藏本人添加附加部门的入口。附加部门仍独立配置角色/覆盖，遵守既有正式权限与范围校验。其他账号不能编辑内置管理员，详情模式及无部门授权管理权限时，部门策略控件保持只读。

## 系统治理边界

[ADR 005](decisions/005-system-governance.md) 定义设置、字典、通知与附件。管理写、导入导出、发布、回退及投递管理只使用正式权限；新目录不扩权旧角色。共享配置按拥有层级检查，不能复用多部门账号“任意归属可见”的条件。个人偏好/消息使用明确本人入口；运行时字典另检查 use 和来源资源权限。

敏感发布及回退必须消费绑定会话/部门/动作/资源/版本、五分钟单次有效的重新认证凭据。秘密以运行环境根密钥 AES-GCM 加密并绑定租户/范围/键，DTO/历史/导出/差异均脱敏。密钥须与数据库及文件同时备份并受控恢复，不允许日志输出或在丢失后静默生成替代密钥。

文件只位于允许根目录，随机存储键、内容检测、体积/像素限制和 os.Root 防越界。下载同等检查范围，公开 Logo 只读可信品牌绑定。不可变存储配置保持旧文件可读；软删除后的后台物理清理须可追踪。

SMTP 主机由部署白名单约束、证书验证不关闭，测试发送仅本人邮箱。事件与临时状态事务一致，投递前复验接收账号/归属/正式审批能力，持久化重试可能产生重复外部邮件。此类边界变更必须同步 baseline-security、SQL/UI Skill 和对应 AGENTS，并扩展 governance/SMTP 真实集成及允许/拒绝测试。

公共设置/字典的最新边界见 [ADR 007](decisions/007-global-governance.md)：仅工作空间公共管理，拒绝旧组织目标与覆盖写入，旧受限授权不自动升级。动态来源、附件、消息和业务关联继续执行自身权限及数据范围。业务接入由 baseline-shared-capabilities 路由，不能把公共能力等同于公开数据。

通知中心遵循 [ADR 008](decisions/008-notification-center.md)：独立正式 notifications:send、服务端组织展开/全部范围校验/账号去重/幂等。正文为不可信 Markdown，禁止原始 HTML/MDX、危险 URL 和任意外部图片。通知附件需要账号/有效归属/通知文件绑定 SQL 校验；收件人例外入口不放宽通用 files:read。附件由发送者拥有，不允许绑定其他人的文件；绑定后禁止删除。同步权限 Skill 与负向回归。

## 页面 WebMCP

[ADR 009](decisions/009-webmcp.md) 的本机开发服务要求 loopback、精确 Host/Origin、Bearer 与显式页面连接；setup 只接受 allowlist 客户端和已连接页面，不提供任意命令/路径。密钥在本机 0600 文件和页面内存，配置/argv/URL 无密钥；SDK sessionId 只做路由标识。开发服务器提供仅 serve 生效的 `/__webmcp/connection` 用于把同一份密钥预填进表单：Host 必须回环、Origin 必须同源、`no-store`、无 CORS 头，构建产物中不存在，读取失败即回退手动填写；预填不放宽服务端 Bearer 校验。工具禁任意 JS、缓存/凭证读取和业务提交，账号工具仅当前已授权快照的筛选计数/只读详情。断开、401、退出、刷新、切部门和身份上下文改变时撤销工具，旧句柄执行拒绝。导航白名单与前端权限仅改善交互，不能替代后端授权与范围。新工具必须补注册生命周期、允许/拒绝、字段投影和跨范围用例。生产远程服务须另行设计身份/会话绑定与 HTTPS，不直接将本机服务暴露公网。

工具的权限元数据用于前端目录过滤，不是可信授权；服务端检查和工具自身数据投影仍是必要边界。身份权限变化时撤销不再允许的工具，公开页面不维持已登录工作区的 MCP 连接。

组织、部门、角色的搜索工具仅更改现有页面筛选状态，不返回记录、不提交业务变更，分别要求对应 read 权限和已加载的授权快照。

设置定时发布按 [ADR 010](decisions/010-settings-schedules.md)：排期/取消复用正式 settings:publish 与 ALL，敏感项排期时消费绑定会话/部门/草稿/版本的 settings.schedule 单次证明。到期重建原账号/部门的可信身份并重新校验正式权限、范围、草稿摘要、类型/依赖和版本；不用旧会话/临时权限执行。发布及排期完成同事务，失败不覆盖当前配置；DTO/日志不含证明、密文或底层错误。


账号级远程 MCP 见 [需求与实现方案](mcp-service-plan.md)（首阶段开发实现，验收状态见交付记录）。开发使用 baseline-mcp-development，功能变动主动确认暴露范围；账号 Token 与本机 WebMCP 配对分离。实施复用可信 Principal、Casbin、SQL 范围及字段投影，Token 固化工具集合与当前正式权限取交集，撤销/禁用实时生效，秘密仅一次显示且不进入日志/配置包。实现入口为 internal/mcp，协议、数据库和客户端验收须分别记录。

远程 MCP 当前开发实现位于 internal/mcp：浏览器 Token 管理继承已有会话/Origin/CSRF，MCP 使用独立 Bearer；绑定账号/部门每请求重建正式身份，不加载临时权。数据库只保存摘要，管理 SQL 按租户与本人过滤。此实现仍待真实数据库安全与客户端验收，不视为可发布。

当前远程 MCP 的精确边界、重新认证、失效触发器、配额/限流与保留期见 [ADR 011](decisions/011-remote-mcp.md)；本机安装仅显式用户确认，短时单次配对证明绑定平台和账号/部门，服务地址固定于助手启动配置。

内嵌助手按 [ADR 012](decisions/012-embedded-assistant.md)：使用能力是正式 `assistant:use`，未授权默认拒绝且不进入旧 viewer 种子；模型/端点/Token 由服务工作空间设置解析，`assistant.token` 密封存储、发布需敏感项重新认证，状态与聊天响应不返回端点、凭证或密文。模型调用只在服务端发起，baseUrl 仅允许 TLS（回环 HTTP 仅本地联调），拒绝 userinfo/查询串/片段；上游错误体不转发，统一映射为稳定错误码。页面工具仍在浏览器执行并沿用注册期权限过滤与撤销语义，模型只提出调用；助手会话仅存内存，退出/401 随 Provider 卸载清理。


## 持久化流程安全

编排使用 Eino Workflow/Graph/ADK，业务节点仍经 Gateway。嵌套来源强制 OriginCapability，继承父调用/深度，事务内互调拒绝。恢复及节点前重建原账号/部门身份；Agent 工具固定版本白名单与当前权限取交集，禁止递归编排。run/read/cancel 权限独立，查询/取消强制 tenant+account；MCP Token 不自动获得新工具。检查点加密绑定 tenant/run/key，不进入明文审计或运行摘要。取消撤销尚未执行的流程审批，已在执行/已提交动作不回滚；审批恢复读取原 invocation，独立动作不因载荷相同共用审批。详情见 docs/orchestration-plan.md（从仓库根解析）。

## 文章评审

文章通过 article.* 能力管理。articles:read/write 仅访问本人文章，articles:review 可读取本租户待审核内容并决定发布；审核仅限直接人类页面调用，禁止作者自审。发布后内容不可变，草稿/驳回修改递增 revision；所有评审落库按 revision 与原状态条件更新。article.apply 只接受 article.assess 注入的进程内可信判定，外部无法传 verdict。AI 没有工具，正文仅作为不可信分类数据。正文不进入事件、调用输入审计、调用结果或 AI 轨迹。敏感读取使用 TransientResult，禁用幂等结果重放并省略持久化数据。

articles.blockedWords 为工作空间安全设置，以换行或逗号分词，复用设置草稿/发布/审计；空词库、配置失败、模型失败或无效输出全部转人工。评审使用投稿时的当前正文版本及评审时已发布词库，不追溯已发布文章。投稿事务写 Outbox，article-moderation Trigger 去重并限制深度；事件身份重新授权。待 AI 状态可由作者重试评审。AI 运行独立记录，失败不会回滚投稿。远程 MCP 显式开放文章列表、详情、创建草稿与投稿；Token 固化工具集合与当前 articles 权限取交集，不开放人工审核和内部结果写入。页面 Agent 工具未开放。
