# 基础安全与授权规则

本规则适用于所有功能，新增能力时按实际威胁边界选用，不等于已经完成生产认证或安全审计。

## 必须保持的边界

AI 工作台 SSE 与 JSON 任务入口共用 `assistant:use`、可信 Principal 及会话/CSRF 边界。流仅投影公开执行阶段、能力名、状态与对调用人可见的回答；原始工具参数/结果、模型隐含推理和凭证不进入进度事件。任务流不自动重试或重连以防重复业务执行，切换聊天不撤销运行；身份切换必须释放旧作用域流。运行记录查询仍强制租户/账号，关联审计使用服务端补齐的可信租户，不能接受客户端租户标识。

| 控制点 | 本项目实施位置 | 开发时必须考虑 | 验证 |
|---|---|---|---|
| 身份可信 | system/identity，Principal，transport | 凭证/会话验证、默认拒绝、身份上下文，不能信任客户端 tenant/owner | 会话与 HTTP 拒绝用例 |
| 操作授权 | system/identity（Casbin model/policy） | 资源/操作、租户域、失败拒绝、撤销/缓存/跨实例失效语义 | RBAC 允许/拒绝、即时撤销 |
| 数据范围 | dataaccess + repository + 参数化 SQL | 所有访问入口一致，租户条件永远保留，单记录写入原子约束 | 隔离 PostgreSQL 的五类 scope 与越权 ID |
| 字段保护 | Goa Result/Payload + SQL 投影 | 读写白名单、敏感新增字段、导出与日志；不能只靠 UI 隐藏 | 响应投影和敏感字段负向用例 |
| 输入和资源限制 | Goa 验证、应用不变量、DB 约束、HTTP 超时/体积 | 公开接口理由、未知字段/文件/路径等新外部输入、事务边界 | 无效输入、约束与配置测试；新增入口补特定用例 |
| 凭证与错误/日志 | config、.env.example、统一 client/transport | 不提交真密钥，不把 token 放 URL/持久化浏览器存储，不返回 SQL/堆栈，不记敏感正文 | 配置负向测试、diff/日志审查 |
| 浏览器安全 | 同源代理、统一 request | CORS/cookie/CSRF 按认证设计决定，避免通配来源或未经评估的 cookie 组合 | 与选定认证方案匹配的请求/浏览器测试 |
| 依赖和生成链 | 锁文件、DSL/SQL/生成器 | 核对官方版本、兼容性、许可证与维护性；不靠生成代码补丁绕过边界 | 类型/静态/生成一致性及变更审查 |

新功能在实现前明确 resource/action/scope/字段与公开性；新增导出、批量、聚合、下载和后台任务不是授权例外。SQL 不能接受前端提交的范围字符串作为权限来源。

## 当前实现与未启用能力

正式后台已实现数据库账号、Argon2id 密码、默认 8 小时 HttpOnly/SameSite=Lax 会话、令牌摘要、同源 Origin + CSRF、登录限流、停用及密码重置撤销。COOKIE_SECURE=false 仅用于数字 loopback 开发；其他监听要求开启 Secure 并通过 HTTPS 访问。初始密码由操作者显式提供，初始化不能覆盖已有工作区。完整边界与合并规则见 [身份决策](decisions/002-identity-access.md)。

正式 IAM 每个请求读取活跃账号、公司、企业、部门、角色与覆盖策略，没有授权决策缓存。角色权限合并，账号 allow 替换同操作继承范围，deny 拒绝。支持 ALL/ORGANIZATION/DEPARTMENT/DEPARTMENT_TREE/OWN/CUSTOM，SQL 保留 tenant 条件；结构更改校验公司关系、树环和引用。权限管理需额外 access:manage；它是整个工作区的授权管理能力。

开发 token 仍默认关闭，仅保护独立技术 demo，不能作为正式后台凭证。SSO/OIDC、MFA、自助邮箱找回、长期合规审计存储与分布式来源限流尚未提供；现有业务版本/审计及结构化日志不提供长期归档和防篡改合规留存。RLS/OpenFGA 未启用；引入时必须按真实应用数据库角色验证。

## 检查方式

`make test-security` 是可执行入口：认证、配置、RBAC/scope/HTTP 与真实数据库范围的允许/拒绝测试。完整 CI 也运行同一批用例。它验证已有控制点，不自动涵盖未来新增接口；新增能力要扩充测试。

字段分类、公开端点合理性、认证/CSRF/CORS 设计和日志敏感性需审查；本项目没有用脆弱字符串 grep 冒充完整密钥扫描或安全审计。当前未接入依赖漏洞数据库/专用密钥扫描服务，发布策略需要此类工具时再明确选型、版本和失败规则，不把未启用检查写成通过。

临时授权在正式策略基础上补充允许和范围，显式 deny 优先。独立审批、正式权限上限、禁止自批、固定范围、数据库时间过期和原子状态转换见 [ADR 003](decisions/003-temporary-access.md)。修改审批、会话解析或数据范围不能只测长期角色权限，还需运行 temporary_access_test.go 的真实数据库用例。


任何认证、权限控制或数据范围行为变更，必须同步维护权限控制相关的 Skill、目录 AGENTS.md 和安全/架构规则，并补齐受影响的允许与拒绝测试；交付说明列出同步位置，不允许只改代码。

多部门授权以 [ADR 004](decisions/004-department-memberships.md) 为准：当前部门验证、角色/覆盖隔离、正式范围保护持久授权、任意归属 SQL 过滤及临时权限部门绑定缺一不可。不得合并跨部门授权或以 OWN/临时权限写入另一部门的持久策略。


内置管理员账号仍禁止停用、删除及移动受保护主部门；界面中主部门策略的锁定不能连带隐藏本人添加附加部门的入口。附加部门仍独立配置角色/覆盖，遵守既有正式权限与范围校验。其他账号不能编辑内置管理员，详情模式及无部门授权管理权限时，部门策略控件保持只读。

## 系统治理边界

[ADR 005](decisions/005-system-governance.md) 定义设置、字典、通知与附件。管理写、导入导出、发布、回退及投递管理只使用正式权限；新目录不扩权旧角色。共享配置按拥有层级检查，不能复用多部门账号“任意归属可见”的条件。个人偏好/消息使用明确本人入口；运行时字典另检查 use 和来源资源权限。

敏感发布及回退必须消费绑定会话/部门/动作/资源/版本、五分钟单次有效的重新认证凭据。秘密以运行环境根密钥 AES-GCM 加密并绑定租户/范围/键，DTO/历史/导出/差异均脱敏。密钥须与数据库及文件同时备份并受控恢复，不允许日志输出或在丢失后静默生成替代密钥。

文件只位于允许根目录，随机存储键、内容检测、体积/像素限制和 os.Root 防越界。下载同等检查范围，公开 Logo 只读可信品牌绑定。不可变存储配置保持旧文件可读；软删除后的后台物理清理须可追踪。

SMTP 主机由部署白名单约束、证书验证不关闭，测试发送仅本人邮箱。事件与临时状态事务一致，投递前复验接收账号/归属/正式审批能力，持久化重试可能产生重复外部邮件。此类边界变更必须同步 baseline-security、SQL/UI Skill 和对应 AGENTS，并扩展 governance/SMTP 真实集成及允许/拒绝测试。

公共设置/字典的最新边界见 [ADR 007](decisions/007-global-governance.md)：仅工作空间公共管理，拒绝旧组织目标与覆盖写入，旧受限授权不自动升级。动态来源、附件、消息和业务关联继续执行自身权限及数据范围。业务接入由 baseline-shared-capabilities 路由，不能把公共能力等同于公开数据。

通知中心遵循 [ADR 008](decisions/008-notification-center.md)：独立正式 notifications:send、服务端组织展开/全部范围校验/账号去重/幂等。正文为不可信 Markdown，禁止原始 HTML/MDX、危险 URL 和任意外部图片。通知附件需要账号/有效归属/通知文件绑定 SQL 校验；收件人例外入口不放宽通用 files:read。附件由发送者拥有，不允许绑定其他人的文件；绑定后禁止删除。同步权限 Skill 与负向回归。

## 云盘空间（开发中）

空间基础能力使用 `drive:use` 和 `drive:create`；旧权限不自动授予新权限。个人空间按可信租户和账号隔离，共享空间按可信账号或当前部门的成员授权过滤。云盘写能力只接受人类页面来源，工具标签不是授权边界。云盘对象使用 `cloud_drive` 用途并排除在通用文件读取、列表和删除查询之外；云盘下载必须验证空间授权且使用非持久化结果。上传分块及存储键不能进入调用审计。云盘一期尚未交付，完整目标和待验收条件见 [云盘 PRD](cloud-drive-prd.md)。

## 远程 MCP 动态能力目录（现行）

远程 MCP Token 绑定本人和部门，每次请求重建正式 Principal；自动化能力目录与 AI 助手一致，按当前权限动态发现，旧 Token 也获得当前有权使用的新能力。历史固化工具集合不再作为授权条件，`tools` 字段仅为兼容保留。业务调用统一走 Gateway，仍执行来源、租户、数据范围、Schema、幂等、风险和审批规则；manual-only 与 internal-only 能力不进入自动化目录。以下历史 MCP 段落与本段冲突时以本段为准。

## 页面 WebMCP

[ADR 009](decisions/009-webmcp.md) 的本机开发服务要求 loopback、精确 Host/Origin、Bearer 与显式页面连接；setup 只接受 allowlist 客户端和已连接页面，不提供任意命令/路径。密钥在本机 0600 文件和页面内存，配置/argv/URL 无密钥；SDK sessionId 只做路由标识。开发服务器提供仅 serve 生效的 `/__webmcp/connection` 用于把同一份密钥预填进表单：Host 必须回环、Origin 必须同源、`no-store`、无 CORS 头，构建产物中不存在，读取失败即回退手动填写；预填不放宽服务端 Bearer 校验。工具禁任意 JS、缓存/凭证读取和业务提交，账号工具仅当前已授权快照的筛选计数/只读详情。断开、401、退出、刷新、切部门和身份上下文改变时撤销工具，旧句柄执行拒绝。导航白名单与前端权限仅改善交互，不能替代后端授权与范围。新工具必须补注册生命周期、允许/拒绝、字段投影和跨范围用例。生产远程服务须另行设计身份/会话绑定与 HTTPS，不直接将本机服务暴露公网。

工具的权限元数据用于前端目录过滤，不是可信授权；服务端检查和工具自身数据投影仍是必要边界。身份权限变化时撤销不再允许的工具，公开页面不维持已登录工作区的 MCP 连接。

组织、部门、角色的搜索工具仅更改现有页面筛选状态，不返回记录、不提交业务变更，分别要求对应 read 权限和已加载的授权快照。

设置定时发布按 [ADR 010](decisions/010-settings-schedules.md)：排期/取消复用正式 settings:publish 与 ALL，敏感项排期时消费绑定会话/部门/草稿/版本的 settings.schedule 单次证明。到期重建原账号/部门的可信身份并重新校验正式权限、范围、草稿摘要、类型/依赖和版本；不用旧会话/临时权限执行。发布及排期完成同事务，失败不覆盖当前配置；DTO/日志不含证明、密文或底层错误。


账号级远程 MCP 见 [需求与实现方案](mcp-service-plan.md)（首阶段开发实现，验收状态见交付记录）。功能变动核对能力的暴露及授权范围；账号 Token 与本机 WebMCP 配对分离。实施复用可信 Principal、Casbin、SQL 范围及字段投影，Token 固化工具集合与当前正式权限取交集，撤销/禁用实时生效，秘密仅一次显示且不进入日志/配置包。实现入口为 internal/mcp，协议、数据库和客户端验收须分别记录。

远程 MCP 当前开发实现位于 internal/mcp：浏览器 Token 管理继承已有会话/Origin/CSRF，MCP 使用独立 Bearer；绑定账号/部门每请求重建正式身份，不加载临时权。数据库只保存摘要，管理 SQL 按租户与本人过滤。此实现仍待真实数据库安全与客户端验收，不视为可发布。

当前远程 MCP 的精确边界、重新认证、失效触发器、配额/限流与保留期见 [ADR 011](decisions/011-remote-mcp.md)；本机安装仅显式用户确认，短时单次配对证明绑定平台和账号/部门，服务地址固定于助手启动配置。

内嵌助手按 [ADR 012](decisions/012-embedded-assistant.md)：使用能力是正式 `assistant:use`，未授权默认拒绝且不进入旧 viewer 种子；模型/端点/Token 由服务工作空间设置解析，`assistant.token` 密封存储、发布需敏感项重新认证，状态与聊天响应不返回端点、凭证或密文。模型调用只在服务端发起，baseUrl 仅允许 TLS（回环 HTTP 仅本地联调），拒绝 userinfo/查询串/片段；上游错误体不转发，统一映射为稳定错误码。页面工具仍在浏览器执行并沿用注册期权限过滤与撤销语义，模型只提出调用；工作区 Agent 问答按本人账号与会话保存在 ai_runs，页面工具的运行状态与原始结果只存 AES-GCM 加密检查点；浏览器内存中的消息在退出/401 或身份、部门切换时清理。浮动面板统一使用 Eino 工作区 Agent，WebMCP 调用原生中断后由当前浏览器执行；恢复凭证须经 SQL 原子消费并绑定租户、账号、部门、调用 ID 及有效期，不能扩大业务权限。


## 持久化流程安全

编排使用 Eino Workflow/Graph/ADK，业务节点仍经 Gateway。嵌套来源强制 OriginCapability，继承父调用/深度，事务内互调拒绝。恢复及节点前重建原账号/部门身份；Agent 工具固定版本白名单与当前权限取交集，禁止递归编排。run/read/cancel 权限独立，查询/取消强制 tenant+account；MCP Token 不自动获得新工具。检查点加密绑定 tenant/run/key，不进入明文审计或运行摘要。取消撤销尚未执行的流程审批，已在执行/已提交动作不回滚；审批恢复读取原 invocation，独立动作不因载荷相同共用审批。详情见 docs/orchestration-plan.md（从仓库根解析）。

## 文章评审

文章通过 article.* 能力管理。articles:read/write 仅访问本人文章，articles:review 可读取本租户待审核内容并决定发布；人工审核仅限直接人类页面调用，禁止作者自审。发布后内容不可变，草稿/驳回修改递增 revision；所有评审落库按 revision 与原状态条件更新。article.record-review 只在 pending_ai 下写入 verdict、只接受 OriginWorkflow，并返回归一化 decision 供流程分叉；article.publish 声明 high + confirm，自动化来源只能产生审批卡，必须由人在审批队列确认后才公开（多人部署可换成 four-eyes，要求另一名具备 capability:approve 的账号批准）；article.reject 只接受 OriginWorkflow 或 OriginApproval 且要求 review_code 为 blocked|suspected。两者都要求 review_code 与状态、版本同时匹配，页面、Agent、API、MCP 直接调用无法绕过。Agent 只能读取正文（article.get 工具），正文作为不可信数据。正文不进入事件、调用输入审计、调用结果或 AI 轨迹。敏感读取使用 TransientResult，禁用幂等结果重放并省略持久化数据。

articles.blockedWords 为工作空间设置（系统设置 → 文章审核分组），以换行或逗号分词，复用设置草稿/发布/审计。已发布词库是确定性的：命中而结论不是 blocked 时 record-review 冲突失败，任何模型转述都不能覆盖。未配置或空词库视为"没有确定性规则"——发布仍由另一名审批人放行，因此不再阻断流程；设置读取失败按 unavailable 失败而不是静默跳过。评审使用投稿时的当前正文版本及评审时已发布词库，不追溯已发布文章。投稿事务写 Outbox；旧的 article-moderation 事件策略已移除，评审只由 article-publish 流程执行，避免同一次投稿被两条路径重复评审。待 AI 状态可由作者重新发起流程。AI 运行独立记录，失败不会回滚投稿。远程 MCP 显式开放文章列表、详情、创建草稿与投稿；Token 固化工具集合与当前 articles 权限取交集，不开放人工审核、评审结论写入与发布分支。页面 Agent 工具未开放。

插件权限目录：内置插件在注册阶段声明权限元数据，身份服务在处理请求前将其校验合并到本服务实例的权限目录；与既有代码、权限范围或临时申请策略冲突则启动失败。声明不等于授权，未知权限默认拒绝；会话、部门切换及后台重建的 Principal 使用该实例的同一目录快照，显式 deny 仍优先，撤权后重建立即生效。目录不是客户端授权来源，也不改变租户和记录范围。

## Application Runtime

文章 Runtime 的 application/page resolve 复用 articles:read；写绑定按 articles:write 裁剪，不授予权限。元数据仅描述字段，SQL 继续强制 tenant + 本人/审核人范围，分页总数使用相同谓词；列表投影拒绝 body 等非白名单字段。UI Context 不含正文或会话秘密，元数据不输出 Table/Column/Via。页面、保存、审核与发布均继续经过原 Capability Gateway；Runtime 不新增 MCP/WebMCP 写工具。Query 按租户、账号、部门、权限、语言和元数据版本隔离。详情路由 ID 是不可信输入，服务端重新执行记录范围检查。

Runtime v2 的空 permission 目录能力只允许已认证身份进入，具体应用、页面、Provider、创建/编辑命令和扩展在服务端按自身权限裁剪，未知对象不可见；记录读取与写入仍走各业务能力。字段只读/隐藏是呈现规则，不能替代能力 I/O、SQL 或业务授权。派生字段只允许来自已声明输出且不能提交；引用选项沿用项目成员范围。映射不执行代码，拒绝未知路径、原型访问与错误类型；语义快照只输出授权引用和可用动作。

Runtime V3 内置部署定义可用 `authenticated` 声明页面对已验证账号可见。Provider 与事件仍按各自权限投影，授权账号以当前会话 Principal 为准。业务能力控制台的系统绑定只接受固定适配器。调用记录保留本人范围，审批和事件保留 Gateway 的本人或审批人范围。Runtime 绑定仅投影展示字段，排除审批参数、原始调用输入与结果及事件载荷。审批写入复用已有决策接口与条件更新，批准后仍按申请人身份执行。

数据统计页的 `identity.analytics.read` 仅接受已认证的人工页面调用。Runtime 仅对可信内置应用绑定明确声明 `authenticated-provider` 的只读能力。统计按当前租户、账号和部门归属经 Gateway 调用原身份读取能力，按区块应用读取权限。部门分布同时要求账号与部门读取权限。仅返回汇总与有限近期记录，响应数据不写入调用审计。

对无需独立权限码的本人操作，可信内置应用可以引用显式标记 `authenticated-action` 的能力。个人偏好使用此规则投影 `settings.preferences.update`，由 Gateway 和设置服务继续校验当前身份及个人字段白名单。其他应用仍需按能力的权限码投影动作。

Token 创建、轮换和设置重新认证使用 `TransientResult`。人工原子写入保留幂等键，重复请求只返回同一执行状态与事件标识。Gateway 排除瞬时结果的数据字段，也不接受此类写入通过审批转交或替换为编排计划。迁移 00037 清理这三类能力已保存的结果数据，保留调用和事件元数据。


项目任务批量分配复用 assign 子能力，逐项事务与 Outbox；父级不承诺原子。子幂等键绑定可信身份与操作 ID，恢复不能改变租户/账号或绕过成员撤销。网络恢复与已知失败子集重试分别处理，不放宽 Gateway 的外层结果重放。新能力未加入远程 MCP/WebMCP 工具白名单。

会话公开投影新增可选 authorizationVersion（服务端正常返回）：由可信账号上下文、有效权限、授权范围与临时范围生成摘要，不包含 CSRF/Token/姓名。权限代码不变而范围变化也会改变摘要。前端在发布新授权 profile 前取消并清除私有缓存，Runtime 将该版本纳入查询身份；同版本普通刷新保留草稿。摘要只用于缓存失效，不是授权凭证，也不代替记录成员变更后的 SQL 校验。
## Memory Center 当前实现边界

个人记忆的 `memory:read`、`memory:write` 和 `memory:collect` 是独立权限，不允许临时申请；SQL 同时限制可信租户、账号和本人作用域。记忆标题、摘要及纠正历史属于敏感内容，不进入能力调用输入审计、成功事件或持久化读取结果。纠正使用版本条件，删除清除标题、摘要、纠正历史及来源关联，但不删除原始审计和事件事实。来源和事件查询仅允许本人无业务资源的事件，以及 SQL 再次验证属于本人的 AI 运行事件；其他业务资源的来源必须先实现并验证原资源授权，不能仅凭事件操作者身份放行。

当前能力仅接受人类页面或已验证 API 调用，Agent/Workflow 入口拒绝；带 `manual-only` 标签的能力不向 Agent 工具目录暴露。项目记忆入口先通过 Gateway 调用 `project.get` 检查原资源权限与成员资格；内部原子能力仅接受指定名称和版本的可信父能力调用，SQL 同时检查当前账号的项目成员关系和租户，读取后重新检查项目可见性。写入还需要 `projects:write`；项目范围写入与其业务事件在内层事务内提交，外层组合事件在后续事务提交，不声称整体原子。部门和组织记忆分别取正式 `departments:read/update` 或 `organizations:read/update` 的范围交集，IAM 在写事务内解析范围，SQL 对目标资源再次校验；临时授权不扩大记忆范围。业务实体适配目前仅支持 `example_record`：通过 Gateway 复用 `example.record.get`，SQL 再检查当前账号是记录所有者；其他实体类型默认拒绝。持久消费者只复制事件元数据，不复制业务事件载荷；事件日志记录时间不等同于源业务事务的准确发生时间。

`memory:manage` 控制租户分区保留策略的查看与版本化修改，`memory:replay` 控制本租户失败摄取的检查与重放；二者均不可临时申请。保留天数为零表示尚未配置自动到期，本阶段只保存策略，不启动自动清理。重放不改写原始事实，按租户和事件 ID 去重。范围重放使用源事件 ID 的闭区间，每次最多 100 条，仅重置已完成或死信记录；返回最后排队的源 ID，继续处理时从该 ID 加一开始，失败列表提供源 ID。

已验证身份的 HTTP 观测仅保留固定的接口类别、方法、状态与耗时分桶；不记录路径参数、查询串、请求体、响应体或堆栈。该非业务遥测经有界内存队列异步写入并有限重试，队列满、重试耗尽或关闭时有未交付项会记录安全错误码；进程崩溃可能丢失队列内观测，不能当作审计或业务事实。业务事实仍以其现有事务和 Outbox 语义为准。

## 数据库应用定义

Runtime 版本按租户保存不可变完整定义和发布指针，不能保存某个用户裁剪后的投影作为公共版本。定义修改须具备正式 applications:design，发布/回退须具备正式 applications:manage，且仅允许人类入口；版本摘要与修订条件绑定人工确认的具体候选。定义及变更正文不进入调用审计、Outbox 或追踪，记录版本与摘要即可。system-only 启动登记能力在 Gateway 和执行端同时限制系统账号与事件来源，不进入 MCP/Agent 发现。设计 Agent 的固定工具集只生成候选。

Gateway 对人类会话实时重建正式及数据库中有效的临时授权，临时授权与 PermanentGrants 保持分离；后台和审批恢复不借用会话临时权限。撤权、过期和部门变化继续重新检查，不信任调用方持有的旧 Principal。

## Capability 执行方案管理

执行方案管理使用独立 `executionPlans:read/edit/validate/publish/bind/rollback/records` 正式权限（不可临时授予），同时校验目标能力权限。所有管理动作是 manual-only，不进入 Agent/MCP 自动化目录，已知名称直接调用仍由 Gateway 检查来源和权限。平台 Direct 方案不可由租户修改；草稿版本不可原地改变定义，发布与绑定分离。租户绑定 SQL 强制 tenant 条件，更新带 expectedRevision，变更历史和 Outbox 随事务提交。执行方案在调用创建及审批受理时持久化，审批用原账号/部门重建身份并加载原方案；切换绑定只影响新调用。执行记录查询强制 tenant+account，不包含原业务输入输出。当前支持 Direct、受控注册 Workflow 与仅替换同契约只读能力的 Graph。

Workflow Plan 的 Native/Pinned 选择只在可信 Go 调用器中提供，客户端 Request 不接受执行模式。Native 核对当前租户/账号/runId/原始 invocation 与目标能力；Pinned 仅选当前租户或部署 Direct 的已发布版本，两者仍通过 Gateway 的完整校验。发布/绑定检查节点权限、自动化来源、Schema、摘要及可检测依赖循环，切换租户绑定串行校验。Workflow 受理与基础设施运行记录原子提交，原调用保持 executing，最终结果只来自已成功、同账号且 causation 绑定原调用的 Native 记录；失败/取消不能覆盖已成功结果。敏感临时结果、Agent、补偿和人工/内部/系统专用节点不开放给 Workflow Plan 模板。

Graph Adapter 仅消费注册引用与摘要。固定工具限定低风险、非 TransientResult、无 OutputAccess 的原子只读能力，排除人工/内部/系统专用；每次经 Gateway 选择 Direct V1 并重新授权，禁止借活动编排扩大为写入。模型无工具集合，任何 ToolCall 均拒绝；严格输出 Schema 校验后才交给确定性 Workflow 分支，模型不能降低 Native 风险确认。独立 Graph Plan 仅替换同 I/O 契约的非敏感临时结果只读能力，不能产生业务事件；只读 Workflow 也不得新增写节点。调用/输出/上下文字节与绝对超时预算在调用前持久化到原有加密检查点，重启不重置预算；不持久化模型原始答复或提供商错误。参考能力 example.record.assess 复用 example:read，通过 Gateway 读取本人示例记录，默认 Direct 只给保守复核建议；没有新增权限或写操作。

Graph 模型支出前校验当前任务与原调用绑定，并刷新原能力正式权限及激活状态；拥有数据源读取权限不代表拥有原业务能力权限。独立 Graph 结果完成时再次执行该检查并使用当前字段权限投影。


执行方案工作台的引用搜索/编译图检查继承 read 和目标权限，并重新校验当前节点权限及摘要；结构预检使用 validate，仅检查输入和元数据，不执行真实业务或模型，也不发布/验证草稿状态。执行记录与节点轨迹使用 records，SQL 强制 tenant+account+invocation，轨迹仅投影实际步骤起止及时间，禁止返回原始 payload。前端缓存隔离租户/账号/部门/授权版本，绑定弹窗保留原 revision，冲突不得静默改为新修订；图上本地编辑不得作为完整 DSL 上传。新端点仍人工专用，不扩大 MCP/WebMCP 暴露。

### Application Runtime 内嵌 AI

内嵌分析和表单建议要求人工 UI 来源、`assistant:use` 及当前租户已发布 Runtime 引用。记录和关联数据经现有 Gateway Provider 授权，模型只收到声明的字段。表单还校验原命令权限、记录范围及草稿字段白名单。AI 结果仅用于页面展示或草稿，模型无工具，审计不保存提示词、草稿或输出内容。

## 项目批量导入

项目导入复用项目创建权限和可信租户。提交能力只接受人工页面来源，在一个事务内写入项目、所有者成员关系与逐项 Outbox 事件。Excel 解析能力只读取调用者提供的字节，限制文件、解压和工作表大小，允许人工页面与服务端能力组合调用。AI 提取还需助手权限，通过已配置的模型服务处理所选工作表的限量文本。解析和提取的原文及结果使用临时响应，调用历史只保留执行元数据。项目导入能力和解析器均不进入自动化工具目录。
